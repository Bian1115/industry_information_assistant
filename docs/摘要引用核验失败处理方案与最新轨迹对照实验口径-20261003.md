# 摘要引用核验失败处理方案与最新轨迹对照实验口径

分析日期：2026-10-03，Asia/Singapore。对象：当前DeepResearch工作历史摘要及其引用核验。此次只检查当前源码与最新五题存档，未调用新模型、修改生产配置或运行质量对照。下述处理机制属于建议，尚未实现或测出收益。

## 当前行为与可行性

当前正文优先生命周期在生成结束后调用`on_generated`提交摘要，再进行可选Claimify核验。`summary_lifecycle.py:145`调用提交回调；`agent_context.py:465`保存正文并推进覆盖游标；`summary_lifecycle.py:193`明确只更新核验状态，`agent_context.py:493`只更新metadata。因此开启核验不会自动重写或删除摘要内容，不会回退已推进的游标。摘要错误仍可能进入后续上下文。

不能说核验失败完全没有动作：`summary_atomic_citations.py:188`会对完整执行但信息不足的论断启动临时检索、重新选择证据和NLI；绑定环节也有受控修复。但这些是引用、抽取或证据层处理，不是摘要正文的纠错闭环。运行错误与缺证据分开；contradiction不走当前信息不足补检索分支。研究报告还有独立的引用审计，不能与本次摘要处理混作一个机制。

最新选用五题已经有模型输入输出、智能体历史、上下文、检查点和事件轨迹，可以做固定来源离线配对实验。选择同一个初始摘要，让未核验组直接采用，让处理组核验并执行有界修复；最终用独立人工标注评估两份正文和实际上下文。现有脚本仍把20261001路径写在抽样函数中，并且没有处理摘要正文的实验臂，不能直接运行旧脚本就声称完成最新轨迹对照。

## 建议的失败摘要处理机制

目标是修复错误、保留正确重要信息和明确未决状态，不能以核验通过率最大化为目标。处理单位为摘要中的原子陈述，保留父分句跨度、摘要版本、来源ID、原始标识及必要条件。Claimify子论断不忠实于父句时先修复抽取，不能因为核验了改坏的子论断就删除原来的正确陈述。

|结果或原因|动作|理由|
|---|---|---|
|充分支持，父子保真且编号合法|原样保留；程序维护引用|避免不必要改写产生新错误|
|内容有依据，只是引用错配或证据分散|修正来源绑定，按同实体/条件组织必要证据；正文可不改|引用失败不等于内容错误|
|证据不足|仅在冻结来源范围内最多补检索一轮；仍不足时缩窄成实际有证据的表述|缺证据不能当成命题为假|
|支持和矛盾并存，或高分矛盾可疑|至多一次来源受限语义复核，检查同主体、时间、条件和明确反向关系|当前单窗口矛盾优先聚合存在误拒|
|经复核确认原文明确反对，或数字/主体/范围被摘要改错|只改问题原子内容，恢复原文数字、限定和归属；没有可支持的替代且为非重要项时才删除|局部编辑降低对其他正确内容的扰动|
|真实来源冲突，无法裁决|保留双方及条件、来源，标为冲突未决|不能删掉一边伪造一致结论|
|重要事实仍无法核实|移入显式待核实记录，保留原始说法、归属、入口及缺口；不作为确定事实使用|保留研究线索，同时阻止未决结论被当成已证实事实|
|超时、调用/模型/编号协议/预算错误|记执行失败，不触发凭空改写或事实删除；采用明确降级或回退|基础设施失败没有提供内容错误证据|

计划、要求、已发生操作和证据缺口应与研究事实分流：要求核对最新用户消息，操作核对工具事件，计划保留待办属性；混合句拆开处理。未来生效的政策仍是政策事实，不能按助手计划跳过核验。

编辑采用结构化patch：父句/原子ID、旧内容哈希、动作、替代内容、来源ID和原因。只允许对指定跨度执行；URL、DOI和来源标识由程序原样维护。复合父句必须保留其余正确子命题和关系，不能因一项失败整句删除。

修复后重建受影响的分句及引用，再检查保真、来源、数字/单位/比较关系、否定/范围、支持关系和完整输出预算。另检查独立重要信息清单的覆盖；核验已输出内容无法发现生成时已遗漏的事实。没有改动的命题在证据/哈希未变时可复用结果。

初版最多一轮补检索、每条至多一次语义复核、每份摘要至多一轮局部正文修复和重新核验，共享请求/token/壁钟预算。具体预算从预实验确定并冻结，不无限循环到通过。

持久化保留raw_summary、processed_summary、处理日志和来源快照。建议实验处理臂先在独立ReplayStore中等待处理结束后提交，原子更新正文、metadata和覆盖游标，并校验父版本/哈希；过时结果不能覆盖新摘要。关键错误未修好或处理执行失败，保留此前有效摘要及未覆盖记录，按原文/外置回读路径重新检查预算；无法容纳则记失败，不静默丢掉新历史。若无旧摘要，只能选择显式未核验降级或失败，须事先冻结策略。采用未核验候选的降级样本照样评价错误，不能只评分处理成功者。

待核实区不能自动获得正确重要事实保留分：正文事实保留必须保持原有正确语义和适当确定性；正确事实被无依据降级为待核实，计有效保留损失。可另记线索可恢复率。待核实内容中仍有明确错误的说法，还需在“全部可见上下文错误残留”中记录，不能靠搬栏目消除错误。

## 配对实验设计

主实验：在7个真实触发点恢复实际生成输入/旧摘要/处理后视图与来源范围，取其自然生成的初稿S0作为共同输入。A直接采用S0；B对同一S0运行核验并完成上述处理得到S1。附加C只核验、不改正文，用来测检出能力及审计成本；其正文哈希应与A相同，静态正文质量应相同。这里A/B/C只是文档标签，可按实现重命名。

要验证当前摘要生成机制本身时，在冻结的实际输入上重新运行一次生成，各臂共享该输出，再配对处理，作为独立重复而非把不同生成结果直接当配对。原稿来自旧摘要或外置预览的情形必须标注输入范围，不能将核验器回读的额外全文倒算成生成模型见过的内容。主实验所有臂使用相同冻结来源；需要开放原始快照补证时另列扩展实验并计入读取成本。不得用后续研究阶段才发现的材料修复此前摘要。

多次摘要更新的单点配对固定同一个previous_summary，衡量局部净收益。累计机制另从相同初始状态按已保存外部记录分别重放，各臂继承自己的上一版处理摘要；这只是固定轨迹累计回放，不等于在线Agent行为因摘要改变后的完整研究。若要比较最终报告错误率，必须在配对上下文上调用相同下游任务/Writer重新生成，并独立评价最终报告；现有报告不能代表修改摘要后的结果。

人工清单在看输出前由任务及其可见原始输入建立，包括重要事实、条件、用户要求、操作状态与严重证据缺口；测试标注隔离于生成、检索、复核和修复。实际运行可用来源提取的在线清单，但不是人工真值，其开销属于处理成本；是否开启在线清单需固定，并可单独消融。完整评价最终正文，不仅评分Claimify抽出的论断，还覆盖被筛除父句、原始遗漏、未决项和被删项。评审盲于实验臂；人工裁决证据关系，模型只辅助筛查。

## 核心指标与分母

|指标|主口径|
|---|---|
|最终错误率|最终确定性事实中，经独立裁决与来源冲突或无充分依据的原子事实数/最终确定性原子事实总数；另分报明确错误、无充分依据、无法裁决|
|错误残留与修复收益|最终残留错误的绝对数；原稿已知错误中真正纠正的比例；修复新引入错误数；另检查全部可见上下文的错误残留|
|重要事实保留率|最终完整且正确保留的活跃重要事实数/从生成实际输入独立标注的全部活跃重要事实数；生成已遗漏的事实也留在分母|
|误删/损害率|S0中原本正确的事实，在S1中被删除、改错或无依据降级而失去有效含义的数量/S0中原本正确事实总数；另报其中重要事实损害率|
|新增token|同一输入下B全链路真实LLM usage减A全链路usage；生成公共成本另列，失败、重试、复核、重核验全部计入，cached已包含在prompt内|
|新增耗时|B完整壁钟减A完整壁钟；同时报告生成、核验、检索、复核、正文修复与重核验各阶段，嵌套耗时不能直接相加|
|执行失败率|超时/调用/解析/预算/持久化等导致无法完成处理的摘要次数/尝试次数；逐条失败率另报|
|内容未决及采用情况|执行完成但仍不足/冲突的比例；修复采用、降级、回退和最终输入超预算的次数，不能混称执行失败|

零事实输出的错误率记N/A而非0；同时报告输出事实数及重要事实保留率，避免删光就“零错误”。明确作废/被真实新要求替代的事实按活跃范围处理，不计误删。重复事实去重，必要关系不能因拆解而丢失。报告按题宏平均和事实微平均，列逐题逐触发点结果；失败者纳入全部尝试，质量另报最终实际采用的回退/降级输出。

LLM新增生成量与embedding/rerank计量、本地NLI输入token及资源开销分列；NLI输入token不当LLM API token相加。API价格未冻结时金额保留未知。评估裁判的成本另列，不混入线上机制新增成本。串行或固定并发、缓存冷/热状态需各臂一致；5题小样本先报告逐样本和范围，不强调不稳定的P95或显著性。

## 理由、失败样例与局限性

历史自然摘要实验的GPT暂定标签中，257条可裁决论断出现37条正确论断误拒、6条问题真检出、4条漏放，正确论断误拒率14.98%。这些不是最新轨迹人工金标，只用于解释为何不推荐“未通过即删除”。已有提升60.38%被拆成提升至60.38%、多地措施被加强为各地全部采用、支持与噪声矛盾同时高分等案例，分别要求保真检查、范围保护及冲突复核。相关来源：[历史误拒漏放根因](五题引用核验精确率偏低与误拒漏放根因分析-20261003.md)、[已有证据组合与冲突复核方案](引用核验证据组合与冲突复核改造方案及验收口径-20261003.md)。

Claimify研究强调抽取论断需要保持上下文和原义，抽取结果不能直接作为摘要真假裁决；ALCE分别评价正确性及引用质量，这支持保留不同指标，而不是用NLI支持比例代替错误率。来源：[Claimify论文](https://aclanthology.org/2025.acl-long.348/)、[ALCE论文](https://aclanthology.org/2023.emnlp-main.398/)。上述论文没有验证本方案在此项目的收益。

已测量：此次本地读取最新选用五题历史，共4题7次自然摘要提交，并记录来源与实现哈希。间接推断：当前只有核验状态更新，处理闭环需要新增；局部、来源受限的修复预计比整份删除更有利于控制信息损失。尚未评估：本方案处理后的错误率/事实保留率/误删率、新增成本及处理失败率，模型裁决与人工一致性，以及最终报告质量净收益。

建议先完成独立回放处理臂和人工标注入口，在最新7点做预实验，按失败样例调方案；正式效果验证另选独立轨迹。第35题可强制生成补充样本，但必须与自然触发组分开，不将强制核验开销外推为所有任务都会增加的开销。当前交付为可行性及处理方案，没有改变生产流程。
