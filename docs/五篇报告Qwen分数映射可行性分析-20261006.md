# 五篇报告Qwen分数映射可行性分析

分析日期：2026年10月6日。对象为固定五篇报告的Qwen质量均分与既有复核四维分数。分数映射可以显著减少本批分数尺度的偏差，但目前不能证明它修复了质量判断，也不能证明在新报告上达到Claude的表现。以下仅做离线诊断，不调用模型，不修改正式评分、提示词、复核或工作台。

输入为[原始一致性汇总](/Users/bxy/projects/industry_information_assistant/backend/eval/data/五篇报告fewshot复评与复核一致性-20261006/一致性汇总.json)，原始调用和复核口径见[复评分析](/Users/bxy/projects/industry_information_assistant/docs/五篇报告fewshot复评与复核一致性分析-20261006.md)。本次计算结果及逐项训练偏差保存在[分数映射诊断](/Users/bxy/projects/industry_information_assistant/backend/eval/data/五篇报告Qwen分数映射离线诊断-20261006/分数映射诊断.json)。每模型每报告的两次评分先平均，比较5篇乘4维共20个坐标，独立报告数仍为5。

使用最简单的加法修正：映射分数等于Qwen原分减去校准数据中的平均有符号偏差。全量拟合时，统一修正为减2.5；分维度修正分别为深度减2.5、全面性减3.3、可读性减1.4、需求覆盖减2.8。本批映射结果都在0至10内，无需截断或舍入。这些系数只描述当前数据，不作为正式上线参数。

| 离线方法 | 相对复核MAE | 相差不超过1分 | 解释 |
| --- | --- | --- | --- |
| Qwen原分 | 2.5 | 15% | 本批基线 |
| 统一平移，全量拟合后在同批回代 | 0.75 | 80% | 包含待评报告的复核信息，不能作为泛化结果 |
| 分维度平移，全量拟合后在同批回代 | 0.5 | 95% | 同批拟合效果，不能作为泛化结果 |
| 分维度平移，留一报告验证 | 0.625 | 85% | 每次用其余4篇拟合，再预测留下的一篇 |
| 复核维度均值基线，留一报告验证 | 0.475 | 90% | 完全不使用Qwen分数，只预测其余4篇的复核维度均值 |
| Claude原分 | 0.625 | 90% | 本批参照，未做映射 |

留一报告验证没有把留下报告的复核分数用于该次偏差拟合；报告的全部四个维度一起留下。计算的是20个验证坐标的平均误差，每维度每次只有4个校准样本。映射形式已根据看过的五篇分歧选择，因此这仍是探索性诊断，不能当作完全未见测试。全量拟合的0.5更不能拿来宣布胜过Claude。参数与方法选择应限于校准部分，在未参与选择的新测试数据上报告效果，避免乐观估计。[scikit-learn数据泄漏说明](https://scikit-learn.org/stable/common_pitfalls.html)

本批分维度平移的验证MAE与Claude同为0.625，但±1分一致率为85%，低于Claude的90%。更重要的是，不使用报告分数的均值基线反而达到0.475。复核分数范围较窄，向常见分值收缩即可取得较低误差；这解释了为什么单看MAE不足以证明裁判有效。均值基线仅用于检查评价难度，不能替代正式报告评审。Claude本批分数更接近复核，也不能单凭这个结果断言它在所有维度更能区分质量。

按维度看，Qwen的全面性和需求覆盖与复核的排序相关分别约为0.79和0.86，存在尝试尺度修正的依据；深度和可读性分别约为-0.30和-0.35。各相关系数只来自5篇，且存在同分，不能据此推断长期能力。它们提示映射应分维度验证，不能假设所有维度都只是打分偏高。

第46题和第16题的Qwen深度均为7分，而复核分别为4.5和5.5分。同一个仅以原分为输入的函数会给两篇相同的映射分，无法恢复这个差异。可读性也出现逆序：第46题Qwen为9分、复核6.5分，第35题Qwen为8分、复核7分。非递减映射可以把这两者压成同分，但不能将其顺序反转；这属于判断差异，仍需明确评分规则和证据。单调回归可用于拟合非递减分数关系，但不具备补充原分未包含信息的能力。[单调回归官方说明](https://scikit-learn.org/stable/modules/generated/sklearn.isotonic.IsotonicRegression.html)

建议先把映射作为候选校准层，保留原始分数、原始理由和映射分数。冻结评分提示词、模型版本及采样设置后，增加独立复核报告，并覆盖高分、低分和不同类型的缺口；先比较分维度平移，数据足够后再考虑带正斜率约束的线性映射或非递减映射。校准依据应为复核参照，不应直接拟合Claude分数，否则只是在模仿Claude。本批不支持复杂映射或自动学习双裁判权重。

验证需同时看MAE、偏差、±1分一致率、每维度排序及明显缺陷报告能否被识别，并与复核均值基线比较。在新报告验证通过前，可以将Claude作为主要评分参考，Qwen用于提示分歧；不宜将同批拟合后的映射分直接当作已经校准成功的独立第二裁判，也不宜继续默认两者等权合并。这里是使用建议，本次未调整系统汇总方式。

已测量：五篇的统一平移、分维度平移、留一报告验证和均值基线。间接推断：Qwen本批误差包含显著尺度偏差及部分质量区分差异。尚未评估：映射在新报告上的稳定收益、校准后双裁判是否互补、参照的独立复核一致性，以及模型版本或提示词变化后的映射有效性。温度和提示词一旦变化，旧映射需重新检验。
