# Writer 输入去重与程序参考文献实现及回归

评估日期：2026-10-02。对象：LeadWriter 的分章、汇总及修订输入格式，以及程序生成参考文献的链路。

## 修改范围

1. 从 Writer 输入视图删除 `original_excerpt`。原始正文和内部证据视图仍用于按编号回读；不改写冻结运行材料。
2. 输入改为 `facts` 和 `documents`：每条事实一条记录，包含事实文本及原句编号；原句按 `(document_id, sentence_id)` 去重，文字只出现在对应文档的 `original_sentences` 中一次。Writer 不需要字符偏移或段落编号，完整索引仍由程序保存。
3. 假设账本保留假设编号、内容、状态，以及关系编号、事实编号、支持/反驳/不确定类型。移除重复解释及来源字段。取消旧的每假设前五条关系限制，避免反驳或不确定关系被隐藏；详细解释仍保留在程序原始状态中。
4. Writer 不再负责另报 `citations/references` 数组。程序按章节正文、执行摘要、核心结论和未来展望中的实际 Markdown 行内链接，生成去重的参考文献，按首次引用顺序编号。来源标题、作者、日期优先取读取器保存的元数据；历史来源目录仅用于元数据回退，未再次引用的条目会被移除。
5. 删除汇总中重复的全来源目录，所需 URL 已包含在文档证据及章节内容中。

没有实施关键事实筛选：汇总仍保留全部事实和原句，章节正文仍完整传入。引用核验开关及其默认关闭状态保持原有逻辑。未编号的历史短正文通过 `legacy_sources` 单独展示，没有伪造原句编号。

## 定义与例子

旧程序所称“证据包”是按来源、原句组合及摘录分组的引用材料，多个事实可以共用一个组。因此 37 条事实被组织为 32 个组，不代表丢失了 5 条事实。

新版直接使用每条事实一条引用记录的结构。假设原句为“项目于2023年投运，服务人口6000人”，两条事实“投运年份为2023年”和“服务人口6000人”都可引用该句；事实记录有两条，原句文字只保存和展示一次。

“汇总只提供各章结论与关键证据”是一项后续可选优化：汇总使用各章结论，形成跨章节判断或处理冲突时读取双方相关事实和原句。它不是本次已经实施的筛选策略。

## 逐类回归与失败样例

八个测试文件，共 147 项离线测试通过，失败 0，错误 0，跳过 0。新增十项测试位于 [test_Writer证据去重与程序参考文献.py](/Users/bxy/projects/industry_information_assistant/backend/test/test_Writer证据去重与程序参考文献.py)。其他测试覆盖正文编号、引用核验开关、Writer 生命周期、假设关系、来源追溯及限定网站交付。

- 原句重叠：两条事实分别引用 `[s1,s3]` 和 `[s2,s3]`，`s3` 只展示一次，各事实引用范围保持不变。
- 同名句号编号：不同正文均有 `s000001` 时，文档编号不同，两句仍分别展示。
- 事实筛选：分章仅选择某条事实时，不额外展示其他事实独占的原句。
- 历史未编号材料：不编造正文或原句编号，不能把事实摘要当成原句。
- 账本尾部冲突：反驳和不确定关系排在第五条后仍完整展示，精简不改变极性。
- 模型误报来源：正文引用 A，模型另报未引用的 B，程序参考文献只有 A。
- 旧版残留引用：修订把 A 替换为 B 后，参考文献移除 A，保留 B。
- 首尾引用：摘要、结论、展望中的行内链接也参与参考文献生成。
- 元数据和重复链接：优先使用原始来源标题、作者和日期；相同 URL 多次出现不重复编号；图片链接不当成参考文献。
- 开关关闭：输入整理和目录生成不触发语义引用核验。

旧第 35 题的失败样例是完整汇总上下文超出预算，在调用模型前被拒绝。此次仅离线重放输入与机制回归，未重新生成最终报告。

## 局限性、结论与下一步

**已测量**：事实绑定与原句文本完整保留，用户提示词减少 7,149 token，147 项机制回归通过。

**间接推断**：按旧开销估算，新输入低于旧预算，能缓解已观察到的汇总输入超预算。

**尚未评估**：真实端到端成功率、模型对新输入结构的实际引用选择、最终报告质量及评分。程序生成参考文献只整理实际行内链接，不判断论断是否被原句支持；此项仍由引用核验开关控制。

下一步可在单独授权的运行中复测第 35 题并比较报告质量；如果后续证据规模继续增长，再设计关键事实筛选与按编号回读机制。
