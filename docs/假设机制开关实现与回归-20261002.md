# 假设机制开关实现与回归

评估日期：2026-10-02。对象：研究假设生成、Scout 事实与假设关系分析、Writer 假设账本与结论映射的开关及配置生命周期。

## 使用方式与配置口径

默认开启，与当前研究行为兼容。后端环境变量设置全局默认值：

```dotenv
RESEARCH_HYPOTHESIS_ENABLED=true
```

每次调用 `/research/stream` 可以传布尔值 `hypothesis_enabled` 覆盖该运行的默认值：

```json
{
  "query": "分析项目",
  "session_id": "已有会话UUID",
  "turn_id": "本轮UUID",
  "hypothesis_enabled": false
}
```

请求省略该字段或传 `null` 时使用后端默认配置。请求中的 `false` 是布尔值，不能使用字符串 `"false"` 或整数 `0`。服务层同样拒绝非布尔覆盖值；无效环境变量会明确报错。

开关每次首跑时保存到 `ResearchState.hypothesis_enabled` 和检查点。执行阶段只读取保存的开关，不随环境变量变化；技术续跑须保持原值，试图切换会被拒绝。需要改变开关时新建运行。旧检查点缺少该字段时视为开启，保持历史行为。

开关与 `citation_verification.scout_facts`、`citation_verification.report_claims` 独立。

## 开启与关闭行为

| 阶段 | 开启 | 关闭 |
|---|---|---|
| Architect | 输出并初始化待验证假设 | 提示词只要求大纲和研究契约；不要求或保存模型假设 |
| Scout 初搜、深搜、补搜 | 分析事实与假设的支持、反驳和不确定关系 | 提示词及 JSON 示例移除假设任务；保留事实、来源和原句编号 |
| Scout 写入 | 更新关系账本和假设状态 | 不处理模型额外返回的关系，不调用关系更新函数 |
| Writer 分章与汇总 | 读取假设账本，输出结论映射 | 移除账本、假设相关写作任务和映射输出字段；仍保留事实、claims 和引用 |
| 追问继承 | 可继承父研究假设材料 | 继承事实和正文后清空本轮假设、关系及结论映射，不修改父运行 |
| 续跑与交付 | 使用冻结状态 | 同样使用冻结状态，状态查询和完成事件展示实际开关值 |

关闭不影响普通研究契约、事实提取、正文分句、来源列表、报告组装及按实际引用生成参考文献。引用支持性核验仍由独立开关决定。

## 失败样例与边界

以下是本地构造的拒绝/忽略样例，不是新一轮在线评测失败：

- 请求 `hypothesis_enabled="false"`：API 严格校验拒绝。
- 已保存关闭状态，恢复时传开启：报“恢复运行须沿用已保存的假设机制开关；更改开关请新建运行”。
- 关闭时模型返回 `hypothesis_evidence`：普通事实保留，关系忽略。
- 父研究有假设账本，本轮关闭：父材料保留，本轮工作状态不继承假设关系。

**已测量**：开关配置、提示词和模拟响应处理路径，以及 217 项离线回归。

**间接推断**：关闭能够减少假设提示词及关系输出的开销，具体节省量取决于研究规模与模型输出。

**尚未评估**：真实运行的 token、耗时、成功率和最终报告质量差异。未重启运行中的后端，也未改写冻结评测目录。
