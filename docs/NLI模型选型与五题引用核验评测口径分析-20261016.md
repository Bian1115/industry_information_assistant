# NLI模型选型与五题引用核验评测口径分析

分析日期：2026-10-16，Asia/Singapore。原评估日期：2026-10-07，生产模块离线回放日期：2026-10-06，既有指标复算日期：2026-10-11。

评估对象：用户截图中覆盖5个研究任务、511条论断、296组引用关系的引用核验评测，以及该评测在NLI模型选型中的用途。本次为既有评估的新增口径分析，不重跑模型、不重新标注、不改变历史结果或生产配置。

## 1. 结论与适用阶段

模型选型时应开展这类评测：让候选模型判断相同的“原文证据—论断”输入，与固定参照标签比较，选择适合业务目标的核验模型。选型后还应以同类评测做模块验收和修改后的回归检查。

截图本身不是多模型选型实验。它记录的是既有qwen3-max引用核验模块在固定五题上的离线表现，与Codex独立复核比较；没有在同一实验中对多个候选核验模型进行公平对照，因此不能据此认定qwen3-max是最优NLI模型。独立复核模型在这里提供评价参照，并不自动成为被选中的业务核验模型。

这里的“NLI模型”指承担证据支持关系判断的模型，可以是专门分类器，也可以是以提示词执行该任务的大语言模型。现有结果还受到证据切分、多证据聚合、分数阈值和失败处理的影响，属于核验模块效果，不能全部归因于模型本体。

## 3. 核心指标及逐类分析

以下数值均沿用既有测量，不是本次新增模型实验。

| 指标 | 既有结果 | 对选型的意义 |
| --- | ---: | --- |
| 完整支持识别Precision | 77.51%（131/169） | 衡量放行项中完整支持的比例；越低意味着放行结果中混入更多未完整支持项 |
| 完整支持识别Recall | 91.61%（131/143） | 衡量正常引用能否被保留；不是问题引用检出率 |
| 完整支持识别F1 | 83.97% | 是完整支持正类F1，单独用它排名不能完整反映拦截目标 |
| 与独立复核二分类一致率 | 78.26%（180/230） | 描述与参照的一致程度；不等于人类金标准确率 |
| Cohen’s κ | 0.509 | 描述扣除偶然一致后的标签一致性 |
| 未完整支持检出召回率 | 56.32%（49/87） | 直接对应问题引用被拦下或转待复核的能力 |

正类143条中放行131条、未放行或转待复核12条；负类87条中拦下49条、误放行38条。38条中37条为部分支持、1条为原文矛盾，不能全部解释为现实假事实。

若目标是减少证据不足的引用被放行，应优先比较未完整支持检出召回率、放行Precision及正常引用误拒绝率，再结合延迟、成本和运行成功率作决策。不能直接按91.61%的完整支持Recall选择模型。具体门槛需要根据业务可接受的漏放、误拒和成本确定，本次没有设定或验证新门槛。

## 5. 建议的模型选型流程

1. **固定数据和参照。** 保留相同论断、相同证据版本和统一的完整支持标准，覆盖完整支持、部分支持、不支持、矛盾和无法判断；建议人类复核关键分歧。参照标签独立于候选模型输出，避免用候选模型自身判定作为答案。
2. **在开发集比较候选。** 对各候选冻结模型标识、提示词、输入预算及聚合规则；相同证据不能因某候选的上下文限制而静默截断。若调整阈值，应使用相同开发流程并分别记录，不能假定不同模型的同一数值分数含义相同。
3. **按业务目标选择模型与配置。** 同时报告完整支持Precision/Recall/F1、问题引用检出率、误拒率、unknown、调用失败、延迟与成本。“最好”应指满足质量和资源约束的候选方案。
4. **冻结后在新任务上验收。** 当前五题已用于诊断，应继续作为开发回归材料；补充未参与选型的新研究任务作为测试集。同一报告及重复论断按组处理，避免相近内容跨开发与测试；只有五个任务时，不宜通过随机拆230条论断制造独立性假象。
5. **接入系统后验证收益。** 单独比较核验开启与关闭时的最终报告支持性、覆盖率、误删和成本，确认模型判别提升能转化为整体收益。模型、提示词、阈值或证据处理变化后继续回归。

开发阶段用于选择，测试阶段用于最终估计效果；反复用测试结果调参会引入选择偏差。方法依据：[scikit-learn官方交叉验证与分组评估说明](https://scikit-learn.org/stable/modules/cross_validation.html)。以上是建议流程，本次没有实际执行候选比较或新增测试集。

## 6. 局限性与测量边界

- **已测量：** 既有qwen3-max核验模块在固定五题、230条可判断且带引用论断上的离线表现，以及相对于独立模型复核的分歧；本次仅核对和解释这些既有结果。
- **间接推断：** 该数据形式适合开发阶段候选比较；时态、范围和统计分母应作为重点检查类别。改变模型或聚合规则可能改善结果，但不能从现有结果推断改善幅度。
- **尚未评估：** 本次不存在多候选同条件排名、独立人工金标、未见任务泛化、在线核验收益及候选成本延迟对照。独立模型复核不是严格盲评或多人金标；五题内的论断存在相关性，63条复核unknown不在主指标中。

下一步若要回答“选哪个模型”，应另开一次候选模型对比评测，并保存各模型逐条预测和配置；当前可成立的表述是“建立并完成引用核验模块离线评测”，不能表述为“通过对比选出了效果最好的NLI模型”。
