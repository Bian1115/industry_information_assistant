# 事实编号从零连续编号调整与回归

评估日期：2026-10-02。对象：检索正文分批提取合并结果的临时事实编号。本次按用户要求，将 `b1_f1`、`b2_f2` 等含批次信息的编号改为 `f_0`、`f_1`、`f_2`，在一次完整分批合并结果中从 0 连续编号。

原编号中的 `b1` 表示第 1 批，主要方便查看事实来自哪个批次；事实唯一性可以由程序的统一计数保证，因此无需在编号中夹带批次信息。批次索引仍单独写入运行记录。

实现位于 `backend/app/service/deep_research_v2/evidence_batches.py`：新增事实使用当前已接纳唯一事实数生成编号；精确重复事实沿用原编号，不消耗新序号；假设关系同步映射到新的事实编号。模型每批都返回 `f_1` 时，也能合并成不同的连续编号并保持关联正确。同批重复的模型编号仍不能用于关系映射。
