## 逐类问题分析与失败样例

### 1. 引句文本定位与语义支持需要分开

既有诊断中来源含逐词换行，模型把换行改成空格，导致严格连续子串校验失败。两条引句经诊断性空白归一化后可找到对应文本。因此不能仅由定位失败认定整段内容凭空编造；也不能因为归一化成功就认定它支持整条论断。

当前摘要引用解析仍要求模型返回 quote 和 source_id，再由程序检查原文归属、处理部分可验证的 JSON 表示差异并定位。程序计算偏移减轻了模型数字符的负担，但仍存在模型重写引句的入口。

建议：将入库原文保存为不可变快照，程序预先切出带稳定 ID 的句子或片段。模型选择片段 ID，程序回填其原文、文章 ID 和偏移。若模型阅读规范化正文，应保留其到原始文本的映射；若原文是 PDF，另保留页码等定位元数据。不要用任意模糊匹配静默替换证据。

### 2. 摘要当前已分阶段，但证据候选依赖先前编号选择

代码显示摘要生成与最终引用补齐已分离，不能将项目概括为全部字段在一次调用中生成。`citation_batches` 仅遍历当前分句的 source_ids：如果上游遗漏真正支持的文章，下游在这一候选集合内补引用无法恢复它。这是静态机制推断，尚未量化候选遗漏率。

当前代码已允许只引用候选子集；旧报告关于所有候选必须引用的阻塞已被后续改动处理，不应再次作为未修复问题提出。

建议：保留生成时的证据链；对外部或既有论断，增加以论断为查询的证据召回路径。候选全部不足时，可以在预算内扩大检索或返回信息不足，不编造引用。

### 3. 原句真实存在，但不能推出复合或全局否定论断

历史失败论断同时包含“逆向设计研究集中在某些方向”和“未覆盖关键材料体系”。两篇特定方向文章不能单独证明整个检索集合不存在其他方向研究。

既有摘要还同时出现了主动学习研究与“主动学习未出现”的相反陈述。此问题涉及分块作用域和摘要合并，单纯修复字符匹配不会解决它。全局未发现结论必须限定已检查集合、检索日期及覆盖范围，并作为检索过程结论处理，不能归因于任意一篇文章。

### 4. 事实 ID、来源记录 ID、文章 ID、展示序号不同

Writer 的声明协议明确要求 evidence_id 使用 facts[].id，不是 source_id 或参考文献序号；其 normalize_claims 函数只规范结构，不验证事实支持性。摘要里的 source_id 也可能对应包含多个检索结果的工具记录，不天然就是一篇文章。

建议明确映射：片段 ID → 不可变文章快照 ID → 原始 URL/标题；工具记录 ID 作为独立轨迹字段保存。最终参考文献 [1]、[2] 按展示顺序由程序分配，不作为内部检索标识。选错片段仍可能导致语义错引，ID 映射只能保证数据归属一致。

## 建议方案

### 从现有文章生成论断

1. 程序保存文章快照、文章 ID、段落/句子 ID、原文偏移及必要的标题上下文。
2. 按文章或小组文章选择证据片段，借鉴 Claimify 做可核查内容筛选、消歧和论断分解。单篇抽取时文章 ID 由调用上下文直接绑定。
3. 模型返回 claim 与 evidence_span_ids；不要求模型重新生成 quote 和文章序号。
4. 程序验证片段 ID 属于本次候选，读取精确原文和所属文章，装配最终输出。
5. 以证据及必要上下文为前提、claim 为假设做支持/矛盾/不足判断，检查时间、数值、主体和限定条件。证据只支持半句时拆分或限定论断。
6. 多文档综合时保留全部必要证据；推导结论另存推导过程，不伪装为某篇文章原句。

以上为结合论文提出的工程建议，并非逐项声称由某一篇论文原样实现。

### 已经有论断，要从大量文章中找证据

建议流程为：论断 → 词法与语义混合召回 → 候选重排 → 带上下文的证据句选择 → 支持/矛盾/不足核验 → 程序回填原句和文章信息。BM25、向量检索、reranker 是可选工程组件，未在本项目做对照测试。

检索相似度只帮助召回，不能替代语义支持判断。多个文章可能均支持同一论断，输出应允许证据集合；找不到证据也不自动代表论断为假。语义检索找到支持文章不等于识别最初首发出处；首发归因还要检查时间及引用链。

## 后续验收建议

建立人工标注小集，覆盖数字/单位、时间、否定、代词、多文章联合证据、同文多篇转载、换行、无支持证据、局部未出现与全局不存在的区别。先用 30–50 条做故障筛查，再扩大样本；小样本不代表整体表现。

分别统计论断抽取精确率和覆盖率、支持证据 Recall@K、原文及归属一致率、引用支持精确率、事实被充分支持的比例、无证据情况下的拒绝表现、调用成本。明确分母以及多条有效证据的标注口径，不能仅统计 ID 合法率或 JSON 通过率。

已测量边界：仅引用上述既有运行和机制测试结果，并核对当前局部代码。

间接推断：模型复制文本、候选池不足和跨分块语义扩大可能造成不同类型的错误；片段选择加程序回填可消除由再次生成原句和编号引入的表示风险，但不能保证选对证据。

尚未评估：建议方案的端到端效果、中文领域迁移、真实 NLI 准确率以及项目最新完整运行。下一步应先实现和验证稳定证据片段及程序回填，再评估是否需要扩大全库检索与调整语义验证器。
