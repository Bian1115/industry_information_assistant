# 关闭单条旧输入摘要改造及验证

验证日期：2026-10-01。对象：DeepScout旧输入处理模块的独立模型摘要开关。本次使用本地桩进行机制验证，没有调用付费模型、重跑评测题目、重启服务或切换正在运行的冻结配置。

## 修改口径

新增环境开关 `AGENT_INPUT_HISTORY_SUMMARY_ENABLED`，默认值为0，并在 `backend/.env` 和 `.env.example` 中设为0。新运行的 `input_history.summarize_long_inputs` 为false：不生成单条旧输入摘要，也不使用该分支的缓存摘要。保留 `reference_materials=true` 和 `semantic_summary=true`，因此引用化和整体历史摘要仍执行。

引用化将旧提示词中能够精确对应已保存工具原文的资料，替换为来源编号及回读位置。完整原始记录保留。这是原文外置的一种实现，处理的是旧提示词里的重复资料；原有工具记录外置则处理工具输入和输出记录。

没有调整外置与整体摘要的触发顺序、阈值或Claimify配置。旧冻结快照继续执行原行为；显式配置文件优先于环境变量，应将 `input_history.summarize_long_inputs` 设置为false。为保持旧快照哈希，模型字段缺省值保留原值，新运行默认关闭通过运行配置构造器实现。

代码入口：`backend/app/service/context_policy.py`；配置说明：`backend/README.md`。新增测试位于 `backend/test/test_旧输入历史压缩.py` 和 `backend/test/test_上下文消融配置.py`。

## 已测量的结果

读取本地 `.env` 并构造新运行配置后，确认引用化开启、单条摘要关闭、整体摘要开启，历史回放agent为DeepScout。配置哈希：`821e229fc1dc59db2f60f035868f4b0aa8d157dc920a4d868cf01347a45e1a87`。

运行三个测试模块：旧输入历史压缩、上下文消融配置、摘要提交与Claimify开关。共53项，52项通过，1项PostgreSQL集成测试跳过，付费模型调用为0。

| 场景 | 结果 |
| --- | --- |
| 新运行不设置独立开关 | 单条摘要默认关闭，引用化和整体摘要保持开启 |
| 长旧输入包含已保存正文及未匹配背景 | 正文替换为引用，背景保留，不调用摘要模型，原始记录不变 |
| 单条摘要关闭且总历史达到整体摘要阈值 | 只执行整体摘要，保存历史摘要并推进覆盖游标，没有单条摘要事件 |
| 独立开关显式设为1 | 可恢复单条摘要分支 |
| 恢复既有冻结快照 | 环境开关不会追溯改写快照，哈希保持有效 |

首次测试为53项、51项通过、1项错误、1项跳过。新增的整体摘要测试桩写了原文中不存在的引文“研究背景”，摘要格式检查拒绝保存，随后触发硬输入预算错误。将测试桩引文改为原文中实际存在的“超长背景。”后，全部可运行测试通过；生产摘要校验未放宽。首次记录保留。
