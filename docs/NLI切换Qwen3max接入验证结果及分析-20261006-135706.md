# NLI切换Qwen3max接入验证结果及分析

评估日期：2026-10-06。评估对象：Writer引用审计、摘要消息证据核验和摘要相关证据句核验的模型后端。本次为模型接入及小样本机制验证，没有重新执行开发集5题或长会话评估。

## 实现与配置口径

新运行的核验模型改为 `qwen3-max`，调用现有百炼OpenAI兼容接口，复用 `DASHSCOPE_API_KEY` 和 `LLM_BASE_URL`。请求明确设置 `enable_thinking=false`、`temperature=0`、JSON Object输出。独立核验提示词位于 `backend/app/prompts/Qwen引用支持性核验.txt`，每次只传本批证据和待核验陈述，不回放智能体历史。

当前部署默认核验输入预算为65,536 token，输出上限4,096 token，安全余量1,024 token，单次核验总时间预算300秒，每批最多4对证据/论断。对应环境变量为 `AGENT_NLI_MAX_INPUT_TOKENS`、`AGENT_NLI_MAX_OUTPUT_TOKENS`、`AGENT_NLI_SAFETY_TOKENS`、`AGENT_NLI_TIMEOUT_SECONDS`。摘要核验与Writer新运行均读取并冻结这些参数。Writer的60,000 token写作输出配置保持不变。

预算使用项目的 `Qwen/Qwen3-8B` tokenizer估算完整消息，包括核验提示词、JSON封装和所有证据/论断。组批同时检查条目数与整批输入长度，超预算不静默截断。当前不再受mDeBERTa的512 token限制。官方发布的qwen3-max上下文窗口为262,144 token，最大输入258,048 token、非思考模式最大输出65,536 token；实际核验输入还受项目预算、输出预留与安全余量约束。规格来源：[官方模型文档](https://www.alibabacloud.com/help/en/model-studio/model-qwen3-max)。JSON Object模式支持及请求口径见[官方结构化输出文档](https://help.aliyun.com/zh/model-studio/qwen-structured-output)。

支持、中立和矛盾仍沿现有聚合与门槛处理：支持阈值0.85、矛盾阈值0.5、复核阈值0.8。Qwen返回的是模型自评分数，不是分类器softmax，也不是校准后的正确率。报告使用 `confidence_method=min_pair_max_llm_self_reported_v1`、`confidence_calibration=not_calibrated` 标明口径，并保存逐条理由与请求用量。

旧冻结配置及原始评测文件没有改写，历史快照哈希仍可恢复。若继续执行明确绑定mDeBERTa的冻结配置，会记录 `model_retired`，不会自动加载旧模型或偷偷替换历史模型标签；需创建使用Qwen的新运行。本地兼容类和已下载权重仅保留供历史离线工具显式使用，生产三个核验入口已经移除对本地加载器的调用。

## 失败样例与修正记录

首次回归共163项：149通过、5失败、8错误、1跳过。摘要消息核验报告将 `settings` 通过两条关键字路径重复传入，造成8项执行错误及相关入口断言失败；已移除重复参数。旧摘要门禁用例受部署默认的历史回放/资料引用化配置影响，未触发预期摘要，已将该用例需要的环境显式固定在测试内部，未修改生产压缩开关。

第一次修正后的回归为161通过、1失败、1跳过。剩余失败是空证据路径不应初始化核验器的断言，已恢复按需初始化，空证据直接汇总为缺少证据且不发送API。最终完整回归为162通过、1跳过，无失败或错误。

更新新运行冻结参数测试后，首次定向复核误用了不存在的测试类名，形成1项测试加载错误；修正类定位后1项通过。该错误不涉及业务执行，前后记录均保留。

## 局限性与边界

- 已测量：协议与预算机制回归、真实API的三个合成样例、超过512 token的一条证据、部署参数与新运行冻结行为。
- 间接推断：原先因512 token限制失败的证据，在低于新预算时可以进入Qwen核验；是否被判定为支持，仍取决于实际证据内容，本次没有回放那些真实失败论断。
- 尚未评估：开发集5题、完整报告核验质量、长会话轮数、65,536 token附近或模型原生极限附近的真实输入、跨批吞吐、生产并发、人工标注精确率/召回率以及自评分数阈值校准。
- 本次没有重启或打断主线程正在运行的服务。运行中的Python进程若已经导入旧代码，仍需在适当时机重启后加载新实现；新运行还须使用新的冻结配置。
- 模型使用API别名，报告保存请求与响应模型标识，但未来别名升级仍可能影响可复现性。旧历史结果与新模型结果不能直接混用为同一评估组。

## 结论与下一步

Qwen核验后端已接入Writer与两个摘要证据入口，非思考模式、结构化输出、输入预算及原有失败区分均已验证，生产路径不再调用mDeBERTa。小样本验证证明接口及基本关系判断可运行，不证明整体核验质量已提升。
