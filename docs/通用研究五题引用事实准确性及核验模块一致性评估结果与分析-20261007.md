# 通用研究五题引用事实准确性及核验模块一致性评估结果与分析

评估日期：2026-10-07，Asia/Singapore。本轮为新评估，不覆盖既有评估。

评估对象：用户指定的通用研究第16、31、35、46、49题的最终报告正文。对应2026-10-03完成的五条轨迹；不是多轮开发集第8、25、26、27、28题。

评审方式：本轮Codex助手直接阅读冻结论断、绑定原文和报告上下文，独立给出逐条支持性判定；不是人工金标，也没有把历史Qwen判定当作本轮答案。事实真假另做权威来源重点核查。

## 1. 主要结论

1. 引用覆盖率为 **57.34%（293/511）**。293条带引用论断中，完整支持143条、部分支持76条、不支持6条、直接矛盾5条、无法判断63条。严格完整支持率为 **48.81%（143/293）**；排除无法判断项后为 **62.17%（143/230）**。这些是“所引证据是否支持该论断”的比例，不能当成全部现实事实的准确率。
2. 在230条有引用且助手能判断的论断上，助手与生产核验模块冻结回放的通过/不通过一致率为 **78.26%**，Cohen’s κ为 **0.509**。相对于助手严格口径，模块支持精确率77.51%（131/169），支持召回率91.61%（131/143）。
3. 模块相对于助手严格口径误放行38条，其中37条部分支持、1条直接矛盾；误拒绝或转待复核12条。因此“误放行”不等于38条现实为假，主要是限定条件或强度没有完整保留。另有11条助手无法判断的证据被模块放行，不并入主指标的确定性错误。
4. 原五条轨迹的在线核验开关全部关闭，状态均为not_executed。**本轮比较对象是2026-10-06保存的生产模块离线回放，不是五条原轨迹当时实际执行的在线核验。原运行在线一致性尚未测量。**
5. 14条重点事实核查发现：完整正确6条、错误4条、部分正确3条、未能确定1条。按12个命题组去重后为5/4/2/1。抽样有意包含高风险项和正例对照，不能据此估计五题总体事实准确率。至少已确认国标实施状态、博物馆城市、近红外实验任务以及NHS资助偏好对象四类事实错误。

## 3. 判定口径与测量边界

| 标签 | 本轮含义 | 二分类主口径 |
| --- | --- | --- |
| full | 引用合起来支持完整命题，对象、数字、分母、时点、条件、状态和强度一致；允许有证据的有限推断 | 通过 |
| partial | 核心部分有据，但关键条件、归属、范围或强度有丢失或增加 | 不通过，需修正 |
| unsupported | 可读的所引证据未提供该命题，或未绑定引用 | 不通过，需补证；不代表现实为假 |
| contradicted | 原文与命题直接冲突，例如任务对象或年龄范围换错 | 不通过 |
| unknown | 来源未绑定、乱码、导航、验证页、窗口不足或全文未读等，无法可靠判断 | 排除主指标；业务口径列为待核实 |

模块supported对应通过；unknown、missing_evidence、invalid_citation、contradiction均对应未通过。模块unknown在本报告中只表示不足以放行，不能解释成事实错误。主指标排除助手unknown，同时保留模块unknown，因为后者是需要评估的模块输出，而不是评价缺失。

报告上下文也参与判定。尤其第46题有关2025年建筑指标的段落和表格明确处于规划目标语境，不能机械把每条“到2025年”都算成已完成；只有预期被改成已实施、对象或数量条件被加强时扣为partial。

无引用218条按透明规则记unsupported，未逐条外查真假。293条带引用论断逐条直接语义复核，296条引用关系均保留判定。现实真假方面，只对14条指定重点事实进一步核查；其中双流预处理两条依据冻结的原刊作者摘要，重新打开网页未完整展开，未声称读取新全文。

发现历史材料时已看到汇总及少量样例，之后阅读材料隔离历史裁判标签和模块输出。这是独立给出理由的复核，**不是预注册严格盲评，也不是两位人类标注者的一致性实验**。

## 9. 局限性与尚未评估项

- **已测量**：冻结最终报告的引用覆盖、293条带引用论断支持度、无引用218条的确定性标记、296条引用关系、796个模块原句证据组对齐、五题保存回放与本轮助手的一致性、14条重点事实核查。
- **间接推断**：误放行中的数字残留和状态强化指向获取及语义判断缺陷；尚未做因果消融证明具体提示或代码位置造成这些错误。
- **尚未评估**：五题全部现实事实的独立真值、原运行在线一致性、所有Scout中间事实、轨迹摘要、检索召回、参考文献权威性评分及成本时延、修复后的新生产模块表现。
- 抽取沿用历史factual标签，可能遗漏命题、包含趋势推断/建议型判断或对行内引用作用域过窄。没有对所有正文重新做第二套独立抽取；110条引用歧义和1条锚点异常仍是抽取层局限。

## 10. 结论与下一步建议

目前更适合把核验模块用作“有据/需复核”的初筛。相对于本轮严格参考，支持召回率91.61%，但在有引用且可判断的未完整支持项中误放行43.68%；再加上证据损坏情况下的放行风险，不能直接把supported转换成事实准确的对外承诺。

建议按以下顺序推进：

1. 先修复正文质量门槛：DOC解析、中文编码/PDF字体、验证码/JS与导航识别；证据不可读时保留unknown，禁止以数字残留或标题推断完整支持。
2. 将命题逐项核对对象、时间、年龄范围、统计分母、前提条件、计划/实施状态和程度词；需要联合多句证据时真正判断完整命题，避免“任一片段相似就支持”。保留partial用于定向改写。
3. 对政策实施日期、关键统计和项目主体增加一手来源核查。NLI一致性解决引用忠实度；二手报道共同错误需要独立事实层发现。
4. 原轨迹实际未在线核验，下一轮选择明确开启report_claims的五题新运行，并保存论断、原句、参数、运行状态。整份正文独立抽取与Writer声明覆盖另算，不能只用声明项通过率。
5. 以本轮50条确定性分歧、63条未知和14条事实重点核查建立回归材料；安排人类对第49题分母/年龄和第16题实验限定做双标仲裁。若要估计总体事实准确率，应对去重事实按题目分层随机抽样并保留选择概率。
