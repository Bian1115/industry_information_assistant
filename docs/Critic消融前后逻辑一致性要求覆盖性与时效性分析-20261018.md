# Critic消融前后逻辑一致性、要求覆盖性与时效性分析

分析日期：2026-10-18，Asia/Singapore。

本次针对已有消融运行作三维补充分析。结论是：**最新两题的逻辑评分小幅改善，要求覆盖没有实质性净提升，整体时效性尚无改善证据，并出现新增的历史材料适用时点问题。** 不能表述成三个维度均已提升。

## 评估对象、数据与配置口径

主分析采用2026-10-17启动的职责分离版Qwen实验，完成原题35（污水治理）和31（博物馆教育）两个配对、四篇报告。每题在第一次Critic前冻结公共首稿，关闭组直接正常交付，开启组允许最多两轮由Critic触发的补搜、重写和复审。生成主模型qwen3.8-max非思考模式，Scout为qwen-plus；两组均保留独立正文引用核验。对比包含整条审核返工链的作用，两组不等预算。

复用已冻结的单一AI评审分数与逐项需求判定，不重新评分，不把内部Critic自评分当作独立效果。逻辑对应辅助维度`logical_coherence`；要求覆盖同时检查`requirements`需求满足评分和逐项`requirement_coverage`。需求满足评分还考虑回答质量与可用性，不能直接改称“覆盖率”。时效性原评分中没有单独的量化维度，本次只核对已有时点缺陷，不补造分数。

原计划五题仅完成两题，其余三题服务拒绝，Claude尝试也未交付。上述未完成项不填零、不纳入质量均分。本次没有新生成报告、调用模型API或恢复已停止的实验。

## 逐题与逐维分析

### 逻辑一致性：博物馆改善，污水的改善被新问题抵消

博物馆首稿在前文承认“技术可能加剧鸿沟”的证据不足，后文却把该假设作为确定前提推出政策；开启稿加入条件及假设不成立时的调整方向，将“国家将建设共享基座”改为建议探索。这改善了前提、推导和建议之间的一致性，对应逻辑评分5.0 → 6.0。

污水开启稿明确设备级LCC不能直接套用于市政管网，并补充CSO和清淤额外成本；但同时新增60%–80%、1%–3%/年、30%–50%、10%–15%等缺保存来源支持的成本范围。前表称应急成本“暂无统计”，后表又给10%–15%，还建议以这些量级核定按效付费基价，形成新的内部冲突和推导缺陷。因此逻辑评分仍为5.0。

**判断边界：** +0.5是已有AI辅助评分的算术均值变化，不能写成“逻辑错误减少10%”或“矛盾率下降”。本次未建立逐条矛盾金标与错误率分母。

### 要求覆盖性：内容更细，但核心缺口没有变成完整满足

污水的8项要求中，财政激励问题完整，其余7项仍是部分满足。支付公式、指标权重、独立计量、应急阈值、合同验收和可审计财务模型没有补齐；新增数字还削弱政府决策可用性，需求满足评分6.0 → 5.5。

博物馆的6项要求前后全部为部分满足。开启稿补充日本制度、财政技术约束和风险，需求满足评分6.0 → 6.5；但具体机构实践、学习效果、分类口径、中国实施责任与阶段目标仍不足。德国从一般学校/职业教育资料外推博物馆制度，没有补成可靠国别研究。原题没有要求必须五国，这类额外扩展不能当成原题硬要求完成。

**判断：** 两题有一升一降，平均需求满足不变，14项要求的完整/部分状态也不变。因此可以说局部回答更细，不能说“核心要求覆盖明显提高”。

### 时效性：没有总体提升证据，补搜新增了适用时点风险

污水两稿均使用了保存的2026年10月苏州政府材料。它在公共首稿已经存在，不能把这一近期来源算作Critic带来的时效增益。2016年LCC方法材料年代较早也不自动代表过时；方法是否适用须看对象和假设，不能仅按年份判错。

博物馆开启稿新增日本注册与资助制度的细节，引用URL标示2009年，保存正文讨论2008年前后的情况，却未在报告中标记历史时点或提供适用于原运行2026年现状的核对依据。已有独立审读明确记录这一缺陷，最终正文仍保留。既有过程复盘也记录：Critic直到最后一次审核才明确指出这一时效问题，返工额度已用尽，识别未转成修复。

**判断边界：** 这证明新增材料存在“历史证据支撑当前表述”的适用性缺口，不证明该制度现实中已经失效。本次仅分析冻结材料，没有在线核对现行法规，也没有穷尽比较所有论断的新旧程度，因此不能量化整体时效提升或下降。

## 历史五题结果的对照边界

2026-10-09旧版五题实验的需求满足均分为4.6 → 4.8（+0.2/10），由非接触感知题4 → 5带动，其余四题该项不变。旧版没有单独的逻辑一致性和时效性评分。

旧版存在能耗数据补上明确年份、感知题补入2026年研究等局部改善，同时房地产稿的“未来十年”仍写2024—2034，并新增会议年度错误。这些历史观察同样只支持“有局部修复”，不足以证明系统性的时效提升。新旧运行生成模型、实现与评分细节不同，不能把五题与两题混合成七个独立样本，也不能直接比较均分归因于Critic升级。

## 失败样例、局限性与证据边界

- 失败样例：污水稿“应急暂无统计”与10%–15%并存；博物馆稿以2009年制度材料描写当前现状；新增德国篇幅没有对应博物馆证据。
- **已测量：** 原评分的重新汇总、14项需求状态的配对比较、四篇正文与评分/映射的SHA-256一致性。全部原评分保持不变。
- **间接推断：** Critic能改善部分前提与建议的衔接，但新增弱依据扩写可抵消收益；这有轨迹与正文支持，仍缺少单独干预对照。
- **尚未评估：** 独立时效评分、陈旧论断率、逻辑矛盾率、剩余三题、Claude完整稿、重复运行稳定性、人类评分一致性与等预算对照。

两题、单一AI单次评分且非严格盲评，无法作统计显著或泛化结论。新出现的证据缺口不等于现实必然虚假；“没有测量整体时效性”也不等于“时效性没有变化”。

## 结论与下一步建议

最稳妥表述：**在两个完成配对中，Critic让逻辑评分平均提高0.5/10；需求满足均分和逐项完整满足状态没有净提升；整体时效性尚未得到量化验证，且存在新增历史材料适用时点缺陷。**

下一步建议仅记录：先在初审固定检查原题全部要求、跨章节矛盾和涉及“目前/现状”的时点适用性；复审核对实际修复而不是篇幅、国家数或数字量是否增加。若后续明确授权复评，可在现有四篇上预先定义时效判据和逐条标注口径，再考虑增加新题及等预算对照。此次不启动后续实验。
