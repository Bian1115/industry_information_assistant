# 通用研究关闭历史摘要可行性分析

分析日期：2026-10-01。对象为首次中文5题运行中已有的全部10个DeepScout模型输入组装点，包括因预算或中断而未完成组装的3个输入点。

结论：必须控制模型输入长度，但现有证据不支持“关闭当前历史摘要就一定超限、无法生成报告”。关闭摘要生成与读取、保留工具外置和资料引用化后，离线重建的10个已观察输入点全部符合项目输入预算。这个结果仅证明这些请求点可组装，不证明后续研究一定不超限或整篇报告能完成。

## 数据与方法

原始运行：[通用研究中文5题首次采集目录](/Users/bxy/projects/industry_information_assistant/backend/eval/data/通用研究中文5题-20260930)。题号35、31、46、16、49，原题未改写，与开发集不重合。该运行五题都没有提交历史摘要，DeepScout的 `summary_version=0`、`covered_seq=0`。

使用真实 [prepare_agent_messages](/Users/bxy/projects/industry_information_assistant/backend/app/service/agent_context.py:233) 和本地Qwen tokenizer，在每个历史 `llm_input` 发起时重建同一上下文、契约、调用身份、已发生消息和已外置来源。将 `semantic_summary=false`、`semantic_verification=false`，保留原有外置、旧资料引用化、历史回读与预算设置。历史读写使用内存存储，模型方法设置为禁止调用；Hugging Face仅使用本地缓存。

七个原来有完整 `context_view` 的组装点，关闭摘要后输入token与原记录逐一相等。另外三个在途组装点也单独重建，未将它们遗漏。

本次网络模型调用0次、数据库写入0次，生产配置未变。离线输入来自首次运行已产生的材料，没有生成新的模型输出或搜索结果，因此属于固定历史上的机制检查，不是完整无摘要对照实验。

第35题第一次组装尤其清楚：历史原始视图62030 token，初步外置后45671 token；摘要未成功提交，继续外置近期工具后降至11368 token。关闭摘要直接走原有外置路径，结果仍是11368 token，省去这次失败摘要的模型请求。

## 当前摘要与报告生成的关系

历史摘要主要作用于DeepScout的长期工作历史。冻结配置的 `replay_agents` 只有DeepScout，Writer不会回放DeepScout的完整原始历史。当前 [章节写作逻辑](/Users/bxy/projects/industry_information_assistant/backend/app/service/deep_research_v2/agents/writer.py:451) 为章节选择相关事实、数据点和证据；[报告整合逻辑](/Users/bxy/projects/industry_information_assistant/backend/app/service/deep_research_v2/agents/writer.py:724) 使用已写章节和来源生成首尾部分，并由程序拼接正文。

关闭历史压缩摘要仍然保留研究中的事实抽取、结构化证据传递和报告写作。历史摘要不是Writer生成报告的直接前置条件。Writer自己的当前提示词如果过长，仍会被本地预算检查拒绝，而且现有DeepScout历史摘要不会自动解决Writer当前输入超长的问题。

## 间接推断与尚未评估

**间接推断：** 对已观察到的这些输入点，昂贵的整体历史摘要不是避免超限的必要步骤，保留外置即可继续发起模型请求。它消耗了预算，却没有提供已采用的上下文压缩结果。

**尚未评估：** 关闭摘要后的完整报告成功率与质量，后续新搜索导致的历史增长，外置后模型是否丢失旧细节，事实与证据是否完整，Writer/Critic实际输入是否超限。

工具外置主要缩短工具记录；旧模型输入和输出仍会积累。更长任务可能最终需要摘要或进一步历史选择。尤其第49题已接近输入上限，不能从10个输入点通过推断所有长任务均可完全不摘要。

## 建议

保留上下文管理，优先调整触发顺序：先工具外置、资料引用化与去重，若组装后的输入仍接近上限，再进行轻量的历史状态摘要。摘要保留目标、已完成工作、关键事实、来源编号、缺失数据和下一步；逐句Claimify抽取可以另行评估其在线必要性。不能仅删掉摘要模块后无条件继续全量回放历史。

生产逻辑尚未修改。完整无摘要与轻量摘要的效果，需要在持续唤醒环境中先用开发集执行对照，不能用本次离线组装结果代替报告质量评估。
