## 指标定义及精确率正类的区别

本报告以问题检出为正类：TP=问题论断被标为unknown/contradiction，FP=充分支持论断被标为unknown/contradiction，TN=充分支持论断被标为supported，FN=问题论断被标为supported。error单列。多窗口金标按必要窗口联合判断，不能把无关窗口没有提及该论断算作反证。

| GPT裁决 / 系统输出 | 未通过unknown/contradiction | 通过supported |
| --- | ---: | ---: |
| 引用未充分支持 | TP=6 | FN=4 |
| 引用充分支持 | FP=37 | TN=210 |

| 指标 | 定义 | GPT暂定结果 |
| --- | --- | --- |
| 问题检出精确率 | TP/(TP+FP) | 13.95%（6/43） |
| 问题检出召回率 | TP/(TP+FN) | 60.00%（6/10） |
| 正确论断误拒率 | FP/(FP+TN) | 14.98%（37/247） |
| 不充分支持论断误放率 | FN/(TP+FN) | 40.00%（4/10） |
| 支持类精确率（以supported为正类） | TN/(TN+FN) | 98.13%（210/214） |
| 支持类召回率（以supported为正类） | TN/(TN+FP) | 85.02%（210/247） |

精确率与召回率必须写明正类。98.13%的支持类精确率与13.95%的问题检出精确率来自同一张混淆矩阵，不矛盾：该子集大部分论断本来就是充分支持的。257条的总体二分类正确率为84.05%（216/257），类别不平衡使它不能替代问题检出指标。217/271=80.07%仅是原运行的支持标签占比，不是以上任何一个精确率。

主表是**原子论断终态**对多窗口支持性的评估，包含当前阈值及矛盾优先聚合；不是470个单独premise-hypothesis对的三分类模型测评。要评价纯NLI单对能力，需再给每个窗口对标supported/contradiction/neutral，并用原始分数单独评分。

具体样例：

- **16-004，误拒**：电容与惯性融合采用组合逻辑、避免繁重训练。W1支持机构与方法身份，W2支持算法细节，两者联合可支持；NLI判unknown。拆散证据后逐窗口评分不能替代联合支持判断。
- **16-006，误拒**：PAC-Net是CVPR2023被动NLOS人体跟踪方法，所选W5直接支持，NLI却因其他窗口的伪矛盾聚合成contradiction。
- **46-010，误拒**：重庆90分及以上系数1.0在W2明确出现，NLI却判contradiction。此处是数值条件理解错误。
- **16-024，误放**：原文是相对精度提升达60.38%，子论断变成精度提升至60.38%；NLI判supported。精确数字相同并不保证数字关系相同。
- **16-047，引用误放**：NLI所选W2/W22仅支持延迟减少超过100ms，没给“相对纯惯性方案”的比较对象。完整S1有比较对象，因此要分开选证据与整条链；完整英文题名另待核对。
- **46-012至014，检出不足**：多地措施合集被拆成长沙、太仓、淮北各自实施全部六项。输入没有城市与措施一一对应关系；这三条确应暂不通过，不应全部认作NLI误拒。
- **49-001至003，来源归属加强**：输入把20–35岁、60%–81%、美学动机归属小牛/原创力/Nature等，子论断加上BMC。BMC被描述为年龄性别表格，未确认它逐一支持这些具体结论；49-002、003被NLI放行。
- **49-014，标识改坏但未通过**：子论断URL删掉-023-，正确URL在W4。系统最终判unknown，二分类上算检出了不充分支持，不能称它正确识别了URL错误的根因。

被判unknown/contradiction的43条确定项中37条被GPT认为有充分支持，是目前初评最明显的问题：未通过列表中大量条目需要复核，不宜直接据标签删句。10条问题项也不是独立错误事实金标，而是引用不足或改写风险。
