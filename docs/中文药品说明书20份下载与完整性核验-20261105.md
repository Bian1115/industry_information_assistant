## 失败与局限性

未观察到最终失败文件。
普通 GitHub raw 地址中的 PDF 实际是大文件存储指针，不能当作说明书正文。本次改用大文件内容地址，并检查 `%PDF-` 文件头与发布者校验值。

- **已测量**：文件数量、实际字节数、PDF文件头、逐文件SHA256；完整下载时另核对ZIP内PDF数量和压缩包CRC。
- **间接推断**：与发布者SHA256相同说明下载字节一致，不代表医学内容正确。
- **尚未评估**：PDF逐页渲染、重新统计页数、文本抽取质量、说明书时效性、临床适用性和RAG效果。
