# 参数外置、正文引用与摘要顺序改造及验证

评估日期：2026-10-06（Asia/Singapore）。评估对象：智能体内部工作历史的三阶段上下文处理顺序。本次为新的离线机制验证，保留首次失败记录及最终复核结果，不覆盖历史验证报告。

## 实现和数据配置口径

主要实现位于[agent_context.py](/Users/bxy/projects/industry_information_assistant/backend/app/service/agent_context.py:355)，字段来源定位复用[input_history_view.py](/Users/bxy/projects/industry_information_assistant/backend/app/service/input_history_view.py:18)。新增[test_参数外置正文引用摘要顺序.py](/Users/bxy/projects/industry_information_assistant/backend/test/test_参数外置正文引用摘要顺序.py)；旧来源匹配用例把引用和摘要开关分开配置。

1. **整体阈值前**：回放原文，不根据单段长度提前外置。
2. **第一阶段：旧工具参数外置**。达到整体软阈值后，遍历最近5条历史消息之前的已完成`tool_input`；仅当`arguments`的序列化内容超过`tool_content_tokens`时外置，默认严格大于800 tokens。只替换参数字段，工具名称、请求标识等其他字段保留。引用包含来源编号、原文字段范围，采用前校验持久化来源权限及哈希。
3. **第二阶段：正文引用化**。遍历全部已完成历史中的可识别输入材料、输出成果及工具结果正文，包括最近5条中的正文。即使第一阶段已降到阈值以下，也完成第二阶段遍历。工具结果沿用既有400字符预览加回读标记；短正文若引用后更长则保留。工具错误详情保留完整，第二阶段不连带替换工具输入。
4. **第三阶段：摘要压缩**。两阶段处理后重新计数；仍达到同一个软阈值时，按现有摘要机制处理安全的连续历史及旧摘要。摘要模型收到已处理的视图；只覆盖可安全完成的调用，不覆盖当前输入或在途调用。摘要仍沿用现有格式、校验、版本和原始游标。
5. 原始记录保持完整可回读；过去的外置标记不能绕过本次阈值或最近5条参数保护。摘要关闭时保留已处理历史，并继续执行硬输入预算检查。

“最近5条”按本智能体当前可回放的原始历史消息条数计算，包含模型输入/输出/错误及工具输入/输出/错误；不按5个用户问答轮或5次工具调用计数，摘要、审计日志和当前输入不参与计数。此保护仅限定第一阶段参数外置；它没有给第三阶段另加“保留5条不摘要”的规则。

整体软阈值沿用`min(soft_token_cap, soft_ratio × 可用输入预算)`，默认17000及0.85。第三阶段改用同一软阈值，不再等待原来更高的`summary_ratio`阈值。旧配置字段及冻结快照结构仍保留，原配置计算值记录为`configured_summary_threshold`；实际`summary_threshold`等于`soft_threshold`。模型、会话层摘要和环境配置未调整。

原有逐智能体开关及消融开关仍生效：参数外置需启用该Agent的外置和较早外置；关闭较早外置但启用最近外置时，工具正文的硬预算兜底在摘要前执行。默认配置执行完整三阶段链路。

## 失败样例与修正

首次相关回归77项中出现3项断言失败：`test_legacy_summary_settings_and_cache_cannot_restore_removed_branch`、`test_long_unmatched_text_keeps_references_without_model_summary`、`test_unfinished_and_interrupted_inputs_are_not_referenced`。这些用例设置400-token软阈值，同时期待不触发整体摘要；此前靠更高的摘要阈值隔开两者。第三阶段改用同一阈值后，长历史合法触发整体摘要，与旧断言冲突。未配置返回文本的AsyncMock还产生了未等待协程提示。

修正口径：来源匹配测试夹具默认关闭整体摘要；两项整体摘要测试显式开启。新的同软阈值触发用例保留并验证新的产品行为，不通过恢复更高生产阈值来促成测试通过。首次失败和最终成功均保留原始结果。

## 局限性与结论

- **已测量**：离线三阶段顺序、5条消息边界、整体/参数阈值、处理后的模型输入与控制字段保护，以及76项相关检查通过。
- **间接推断**：先减少旧参数和正文重复，再调用摘要模型，可能降低摘要输入规模和调用机会；没有测量真实任务收益。
- **尚未评估**：真实Qwen分词器的计数、真实数据库来源读取、真实回读行为、摘要保真、延迟成本及30+轮研究能力。
- 未识别、无法可靠定位或引用后膨胀的正文保留原文。最近5条保护是参数外置规则，不是摘要保留条数设置；摘要仍可能覆盖这些消息中的已完成调用。

请求的处理顺序已实现并通过离线机制及相关回归。后续真实实验可沿用现有主实验流程，对照三阶段token计数、摘要调用次数、原文回读次数和最终交付质量。本次没有启动真实多轮实验或重启研究服务。
