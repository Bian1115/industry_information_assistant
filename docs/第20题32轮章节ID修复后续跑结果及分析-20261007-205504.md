## 失败样例与原因

1. **第21轮终止：执行租约过期。** 程序21:53:16完成第二次分析，电源日志显示21:53:14进入Idle Sleep，22:10:25唤醒，休眠1031秒；22:10:27事件写入抛ResearchRunLeaseLost。代码租约60秒、续租间隔20秒，事件落盘要求lease_until仍有效。已测量日志时序；休眠暂停续租导致拒写是有依据的因果推断，未独立记录数据库每次续租，也不将其归为token超限。抓取500和Milvus collection未加载为此前已降级的附加问题，不是最终抛错。

2. **当前恢复判定存在阻断。** 已完整保存检查点1f1c2566-db09-622a-8005-ce0fd3d9871b及2项pending writes：analyze的research结果和branch:to:write。默认aget_state应用pending writes后next为空，但状态仍running/analyzing、completion_reason=not_completed且没有交付；历史同一检查点next为analyze。生产_graph_input仅检查snapshot.next，因为空会报“图已执行结束，应读取报告或补做幂等交付”。因此数据保留不等于现有入口可直接恢复；需要修复对已完成节点pending writes的恢复判定，再验证同run恢复到write。只读核查未修改检查点、未伪造交付、未从更早检查点重放。

3. **任务改写滞后一轮。** 第13、14、17—21轮resolved_query逐字复用上一轮用户原话；原始当前query在运行行和生产输入中是正确的。部分当前意图被修订指令补回，但第20轮未补断连证据、交付与19轮完全相同，21轮又执行20轮补证。不能仅凭source_sentence_ids格式合法判定当前语义保留。

4. **父成果和约束继承错误。** 第12轮选择初始第1轮成果，1200上限退回2400，安全结构丢失；后续16轮恢复1200、17轮更新900仍多数超字数。7/9新交付超上限是已测量的回答不满足要求；因硬检查关闭，不把它当执行失败。19、20轮把资料截止日写为2025年3月，违反固定2026-10-05。

5. **事实及来源错误继续传播。** 回答把Anthropic API SDK作为MCP实现依据，多轮要求NDJSON且排除SSE。直接对照[MCP 2025-06-18正式传输规范](https://modelcontextprotocol.io/specification/2025-06-18/basic/transports)，响应可用JSON或SSE，与稿件的强制表述冲突。这个事后核对不回灌实验；只核查指定历史版本，未证明2026-10-05最新版本、未执行SDK示例。非官方博客也进入只准正式/官方来源的报告。

6. **引用审计结果未等同交付质量。** 15个新增草稿版本的自动引用审计均rejected，常见unknown、missing_evidence、invalid_citation及contradiction；当前audit_only模式继续允许critic和交付，不能将critic pass当成事实支持率。自动unknown并不自动代表事实错误，完整人工评分尚未完成。

7. **历史读取仍有低效和非法ID。** 新增7次成功历史读取，其中第15轮同一调用的2段材料各读3次；另有第12、15轮各1次非法UUID错误且可恢复。本次未出现19次同片段循环，但3次重复说明仍有优化空间。

## 局限性及结论

**已测量**：本段10轮生产任务构建和9轮交付、原会话连续性、301次SDK usage、31次内部摘要、字数、源码哈希、终止错误及检查点pending writes。**间接推断**：休眠对续租的影响、离线路由标注比较、本地token估算和上下文视图变化解释。**尚未评估**：第22—32轮、32轮完成能力、完整人工事实正确率、会话摘要实际触发后的质量与保真、修复pending-writes恢复判定后的续跑、其他题和主题切换。

结论：已有内部压缩机制可以实际生成并采用摘要，本段在未出现新增上下文超限的情况下交付到20轮；第21轮的执行可靠性问题阻止继续，仍有已确认的追问语义、来源与约束问题。当前证据不足以声称项目支持正确完成30＋轮。

建议先修复未交付但存在pending writes的恢复判断，并用暂时防休眠运行器隔离机器休眠因素，在同一会话、同run与累计账本上恢复第21轮；修复任务改写当前轮锚定与父成果约束继承，保留字数软统计并约束写作预算；将容量、语义满足和引用支持分别评估。要实测会话SummarizationMiddleware，还需专门制造超过55705的受控会话，记录保留消息ID、旧摘要合并、API usage、前后token与事实保真。
