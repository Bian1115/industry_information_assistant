# 双裁判评分流程、真实示例与误差复算分析

分析日期：2026-10-28，Asia/Singapore。

评估对象：历史30题参考报告评分器验证中，Qwen/Claude双裁判如何评分、为什么各评分两次，以及0.286分平均绝对误差的来源。

本次从保存的逐条评分结果重新计算26道完整题目的报告总分，并核对事先冻结的GPT参照评分。没有发起模型请求、没有修改历史报告或分数、没有重新判定报告事实。原评估汇总更新时间为2026-10-08 09:38:52 +08:00。本报告是新的复算分析，不覆盖历史评估。

## 一、先明确谁在给谁打分

“裁判”就是负责评价报告的大模型。本实验中的两位裁判是历史配置中的Qwen3.8-max和Claude-opus-5。

本实验评价的对象是从DeepResearchBench中固定抽取的30份官方参考报告，合计758条逐题细则，不是本项目新生成的30份报告。数据来源、报告正文、题目和官方细则已经保存在本地[冻结输入.json](../backend/eval/data/DeepResearchBench参考报告30题双裁判一致性-20261007/冻结输入.json)。

历史执行流程如下：

1. 研究者启动评分脚本；脚本从冻结输入文件读取每道题的研究要求、完整报告正文和该题的官方评分细则。
2. 评分脚本向Qwen发送两次完整评分请求，向Claude发送两次完整评分请求。四次请求都评价同一份报告、同一组细则；每次请求都要求模型逐条给分、说明理由并摘录正文。
3. 每次请求都不包含其他次评分结果，也不包含GPT参照分。第二次评分不要求模型修改第一次评分。提示词带有不同的“重复编号”。
4. 评分脚本检查模型输出的细则是否缺失或重复、分数是否在0—10之间、理由是否齐全，并将有效模型响应及原始响应保存为本地JSON文件。JSON是一种按字段保存数据的文本格式，例如用`score`字段保存分数。
5. 汇总脚本从保存的JSON读取细则分数，在程序内计算每个维度分数、报告总分、两次均分和双模型均分，再把结果保存到本地一致性汇总文件。
6. 汇总脚本用事先冻结、裁判不可见的GPT评分作参照，计算每道题的差异和26题的平均绝对差异。

第5步的实际代码先在每条细则上对同模型两次取均值，再融合两个模型，最后加权汇总。下文为便于手算，先展示每次评分的加权总分，再对总分取均值。因为权重固定且聚合都是加法与乘法，两种顺序数学等价；中间不能提前四舍五入。

代码依据：[评分请求与校验脚本](../backend/eval/scripts/DeepResearchBench参考报告双裁判一致性.py)、[加权与误差汇总脚本](../backend/eval/scripts/生成DeepResearchBench评分页面与分析.py)。脚本要求逐条绝对评分。本次不是复算官方榜单中以待评报告和参考报告相对比较得到的RACE成绩。

## 二、真实第46题：模型具体怎样给分

题目是：

> 房地产行业可持续发展的动力是什么？未来10年国家在政策、资金、导向如何促进该行业有序、良性地发展。

裁判拿到的细则按四个方面组织：全面性看内容是否齐全；洞察力看分析和推理是否深入；指令遵循看是否完成题目指定要求；可读性看表达和结构是否清楚。

### 1. 模型先给每条细则打0—10分

评分提示词给出尺度：0—2缺失或严重偏题，3—4较差，5—6基本可用但有明显缺口，7—8较好但有局部缺口，9—10充分且严谨。模型还必须结合具体细则的说明判断，不能因为篇幅长或引用多就机械给高分。

例如，第46题“可持续发展内涵界定清晰度”要求报告解释经济、社会、环境等方面，并说明“有序、良性”的含义。

Qwen第一次给9分。其理由大意是：报告解释了绿色建筑到环境、社会和治理框架（ESG）的演进，也涉及住房保障等内容，但“有序、良性”的具体含义没有单独定义。

Claude第一次给7.5分，第二次给6.5分。其理由更强调经济稳定、长期价值和“有序、良性”的界定仍不充分。两位模型看到了部分相同缺口，但扣分尺度不同。它说明双裁判可能存在系统性的宽严差异，不能把四次平均当作已经查明的客观真分。

这些是历史裁判的判断，本次只复算其分数，没有重新裁决哪位模型正确。

### 2. 程序按细则重要程度计算维度分数

“权重”表示某项分数在汇总时占多大比重，来自该题的官方细则，不由模型临时决定。

下面是Qwen第一次对第46题“全面性”的六项实际评分：

| 全面性细则 | 模型给分 | 在全面性内部的权重 |
| --- | ---: | ---: |
| 可持续发展内涵界定清晰度 | 9 | 10% |
| 可持续发展动力识别的广度与深度 | 9 | 25% |
| 未来10年国家政策措施覆盖面与具体性 | 8.5 | 25% |
| 未来10年国家资金支持机制探讨的全面性 | 8 | 20% |
| 未来10年国家导向策略阐述的完整性 | 8 | 15% |
| 信息与任务核心目标的相关度 | 9 | 5% |

这六项权重之和为1，所以：

```text
全面性 = 9×0.10 + 9×0.25 + 8.5×0.25
       + 8×0.20 + 8×0.15 + 9×0.05
       = 8.525分
```

一般公式是“细则分数乘各自权重后求和，再除以该维度细则权重之和”。本例分母刚好为1。

### 3. 程序再按四个方面的重要程度计算报告总分

同一次Qwen评分的四个维度和第46题的官方维度权重如下：

| 维度 | 该次得分 | 在第46题总分中的权重 |
| --- | ---: | ---: |
| 全面性 | 8.525 | 27% |
| 洞察力 | 8.125 | 39% |
| 指令遵循 | 8.875 | 19% |
| 可读性 | 8.225 | 15% |

```text
Qwen第一次报告总分
  = 8.525×0.27 + 8.125×0.39 + 8.875×0.19 + 8.225×0.15
  = 8.3905分
```

27%/39%/19%/15%是第46题的权重，其他题可能不同。模型负责细则分数，程序负责固定权重下的计算。

## 三、为什么每个模型评两次

这里处理的是两类不同问题：

- **同一个模型也可能前后给分不同。** 对相同内容和细则分别发起请求，可以观察同模型的评分波动；两次取平均旨在缓和只依赖某一次结果的偶然性。
- **不同模型可能长期偏宽或偏严。** 保留Qwen和Claude两个模型，可以观察模型之间的尺度差异；等权平均旨在减少只依赖单模型尺度的风险。

“两次”不是必须遵守的理论规则，而是额外费用与可观察重复差异之间的工程折中。现有实验没有证明“两次最优”，也没有通过一次、两次、更多次的严格成本效果对照，证明误差一定随次数增加而下降。

第46题四次实际总分：

| 裁判 | 第一次 | 第二次 | 两次平均 |
| --- | ---: | ---: | ---: |
| Qwen | 8.3905 | 8.5330 | 8.46175 |
| Claude | 7.4405 | 7.0155 | 7.22800 |

Qwen两次相差0.1425分；Claude两次相差0.4250分。本题确实存在同模型重复差异，而且两位模型的均分相差1.23375分。平均可以折中这些输出，但不能保证折中后就是现实真值。

全样本重复评分的平均绝对分差，本次从细则分数重新算得：Qwen为0.2033667分（30题），Claude为0.2078125分（26题）。这些数字测的是同模型两次总分的距离，不是相对GPT参照的误差。

历史Qwen配置中，控制输出随机性的参数temperature为0.6，帮助控制随机生成过程的种子seed为1234；第二次提示词的重复编号不同。固定seed不应当作输出绝对一致的保证。这些调用不能直接被当作每次互不影响、随机机制完全相同的严格独立样本，因此不能直接套用“两次使方差减半”等保证。

## 四、双裁判如何得到这一题的最终分数

程序先分别平均每个模型的两次评分：

```text
Qwen均分   = (8.3905 + 8.5330) ÷ 2 = 8.46175
Claude均分 = (7.4405 + 7.0155) ÷ 2 = 7.22800
```

然后程序对两位模型等权平均：

```text
第46题双裁判最终分
  = (8.46175 + 7.22800) ÷ 2
  = 7.844875分
```

本实验每位模型都恰好有两次有效评分，因此也等于四个总分相加再除以4，每次占25%。实际代码只对“两模型各两次有效评分均齐全”的题目计算完整双裁判分数，不用三份输出冒充四份输出。

## 五、0.286分究竟怎样算

先解释术语：每道题都算“双裁判分数与参照分相差多少”，不管高估还是低估，然后对所有题的差异求平均。这叫**平均绝对误差，MAE**。

这里的参照是事先冻结的GPT评分，原始目录名为“助手独立评分”。GPT使用相同题目细则评分，程序也按同样权重算其总分；它不参与Qwen/Claude最终分数的平均。先冻结且不向裁判展示参照分，是为了防止裁判照着参照打分。

GPT参照仍是模型判断，不是人类金标；历史参照采用结构浏览和按细则定位补读，存在长段落截取，并未开展完整外部事实审计。

### 1. 先算第46题的绝对误差

第46题冻结的GPT维度分为全面性7.4、洞察力6.975、指令遵循7.8、可读性7.95：

```text
GPT参照总分
  = 7.4×0.27 + 6.975×0.39 + 7.8×0.19 + 7.95×0.15
  = 7.39275分

第46题绝对误差
  = |双裁判总分 − GPT参照总分|
  = |7.844875 − 7.39275|
  = 0.452125分
```

绝对值符号表示只保留差距大小。例如高估0.4分和低估0.4分，在MAE中都贡献0.4分，不能互相抵消。

### 2. 再平均26道完整题目的绝对误差

30题中有26题完成了两模型各两次评分，61、22、31、84四题未齐全，因此没有计入双裁判MAE，也没有被填成0分。

本次从26题的原始细则分数及冻结参照重算得到：

```text
26题绝对误差之和 = 7.43515625分

MAE = 7.43515625 ÷ 26
    = 0.285967548076923…分
    ≈ 0.286分
```

每份报告在这一步占相同权重，不按报告篇幅或细则数量再次加权。758条是30份报告的细则总数，不是这个总分MAE的分母；四次评分也不是四份独立报告。

## 六、失败样例、局限性与结论

第46题的第一条全面性细则中，Qwen两次均给9分，Claude给7.5和6.5分。双方都提到概念界定缺口，却在扣分尺度上不同。这是模型尺度差异的具体样例，尚未由人类仲裁哪方更合理。

逐题误差中，第65题为0.714125分、第15题为0.7023125分、第73题为0.65525分；平均误差0.286分并不保证每题接近。四道缺少完整评分的题目仍是未完成项，不能将26题结果写成30题完整结果。

**已测量：** 本次读取114份已核查有效评分记录（Qwen60、Claude54），通过比较由文件内容计算出的哈希指纹，检查冻结GPT评分文件没有变化；从细则分数重算26题四次评分总分、融合分和MAE，与历史汇总一致；同时复算同模型两次总分的平均绝对差异。使用十进制计算，中间没有四舍五入。

**间接推断：** 重复评分有助于观察单模型输出差异；双模型有助于观察宽严差异。平均旨在缓和对单次、单模型结果的依赖，不能仅凭这套机制就断言因果收益。

**尚未评估：** 一次、两次或更多次评分哪个性价比最优；严格独立抽样条件下的方差降低；相对领域专家金标的误差；医学专项和临床事实正确性；所有30题完成后的双裁判误差。

结论：双裁判是“两模型逐细则评分、各两次、按固定权重汇总并等权融合”；0.286分来自26道完整题目的报告总分与冻结GPT参照之间的平均绝对差异。它验证的是这一批报告上的模型评分一致性。

下一步建议：若要证明重复两次或融合两模型确实改善误差，应在相同任务子集上比较单次、同模型多次均分和双模型融合；保留原始分数、预算和未见测试任务，并加入人类领域标注或仲裁。未实施前不写“评分两次使误差降低X%”。
