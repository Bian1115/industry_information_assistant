# 段落截断率下降与块长混杂归因分析

## 日期、对象与证据边界

- 分析日期：2026-10-21（Asia/Singapore）。
- 评估对象：如何判断“段落截断率从23%降至7%”来自切分边界改善，而非仅来自chunk变长。
- 本次性质：既有口径核查及控制实验设计；未执行切分、检索或生成评测。
- 已测量：无新增实测指标。23%与7%是用户提出的待核实数字；已查阅的相关文档未提供这组数字的原始运行、分子分母与配置。
- 间接推断：增加块长可能减少跨块段落，原始前后对比不能单独识别策略贡献。
- 尚未评估：两组实际块长、同长度策略差值、置信区间、检索与回答收益。
- 原始结果路径：本次无机器可读评测结果。参考资料见文末；素材核查结果不能替代切分效果结果。

## 一、先锁定指标和数据口径

本问题默认讨论分块器输出的上下文层。若同一段落在多个块中合起来完整，但没有任何单块完整容纳，建议称为“段落碎片化”，区别于预算裁剪导致实际内容缺失。原句引用层本来就按句拆分，应独立评价。

建议在同一批独立标注的参考普通段落上计算：

`碎片化率 = 全部块联合完整覆盖、但无单块完整容纳的段落数 / 固定参考段落总数`。

每个原段只计一次，按原文位置判断完整性；不能按输出chunk数量作为这个指标的分母。内容缺失、整段遗漏、对齐未知、构建失败分别记录，不能把它们当成低碎片化的成功样本。另报告“未被任何单块完整容纳率”，使缺失样本不能通过退出碎片化分子美化结果。

冻结正文、段落标注、文档版本、规范化规则和tokenizer。使用相同来源、相同参考段落做配对比较。表格、记录、列表另分类型。正文抽取、网页返回预算、分块、检索后预算是不同阶段，不同时改动并归因于切分。

## 二、最小控制实验：策略与块长交叉

设旧、新策略为A、B，原、新长度档位为L1、L2。先在同一冻结语料上运行四组：

| 策略 | 原长度L1 | 新长度L2 |
| --- | --- | --- |
| A：旧策略 | A1 | A2 |
| B：新策略 | B1 | B2 |

- A1与A2：旧策略下改变长度档位的效果。
- A1与B1、A2与B2：同长度档位下改变策略的效果。
- A1与B2：整体配置变化，只能说明联合变化后的结果。
- 若两档下策略收益不同，报告交互效应，不能把所有收益归给一个因素。

需固定overlap规则、元数据处理、超长单元处理和内容覆盖要求。若目标是隔离边界选择，可增加双方均无overlap的诊断运行；对本来没有overlap参数的结构化切分器，不人为增加生产兼容机制。父子关系与邻居扩展的收益另做消融。

以下仅为解释用假设数字，未执行：若A1=23%、A2=9%、B2=7%，则沿“旧策略先加长，再换策略”的路径，块长配置变化对应14个百分点，策略变化在L2下对应2个百分点。不能把16个百分点全归于策略。仍需B1判断交互；如果同档位实际长度不匹配，连这2个百分点也不能直接称为纯边界收益。

若原始两组长度参数本来相同，仍需下一节的实际长度核查；不必机械添加一个并不存在的历史长度变化。

## 三、相同上限不等于相同实际块长

结构切分可能提前结束、合并短段或允许超限。因此所有组都保存实际token长度的均值、P50/P90/P95、完整分布、每文档块数、唯一内容覆盖量、重复token开销与超限率。字符上限和token上限不可直接比较。

进一步在开发集扫描长度参数，寻找旧、新策略实际长度分布接近的配置；匹配条件应在查看测试集效果前确定。保留测试集使用锁定配置，仍展示实际分布，不能仅因均值接近就宣布已控制长度。若存在明显残余差异，结论应限定为“同上限”或“近似同长度”，不声称完全排除长度影响。

若现有实现难以匹配，可增加独立诊断基线：在同一文档内约束相同块数、长度范围和全文覆盖，只改变切点是否优先落在段落边界。记录无法满足约束的文档，不用补空白、删除内容或把新策略输出再次硬截断来凑长度。这类诊断支持机制解释，但不替代真实生产策略比较。

在共同可覆盖的长度范围内绘制“实际块长—碎片化率”曲线。同样长度下新策略持续更低，才支持边界选择有贡献；只有随块长增加而共同下降，则主要证据指向长度效应。

## 四、配套指标及逐类分析

| 类别 | 分析重点 | 防止误判 |
| --- | --- | --- |
| 可容纳短段 | 在共同上限内仍被分散的比例 | 更能观察可避免的边界破坏 |
| 接近上限的段落 | 同长度下切点与段落边界的关系 | 避免整体均值掩盖临界段退化 |
| 超长段落 | 超过共同上限的比例及分片情况 | 硬上限下无法单块完整容纳，不直接归罪于策略 |
| 条件、否定、跨句解释 | 主体、结论及限定条件能否共同保留 | 句末有标点不代表段落语义完整 |
| 表格和字段记录 | 表头、单位、时间及行列关系 | 不与普通段落混用分母 |
| 失败、遗漏、对齐未知 | 固定全集的覆盖和失败占比 | 不仅统计成功分块子集 |

可容纳段落必须按双方共同上限定义同一子集，同时保留全量结果；不能各自删掉超长段后比较不同分母。额外计算段内切点数/全部有效切点数，以帮助区分“切点变少”和“切点位置更好”，但该辅助比率本身仍受长度分布影响，不能独立证明归因。有overlap时应分别处理起止边界，不重复统计同一来源位置。

最终检索验证固定上下文token预算B，记录实际使用量，比较完整证据命中率、证据Recall/Precision、重复率及成本；固定Top-K不能控制总文本量。检索器、精排、邻居扩展和生成配置保持一致。结构指标改善只证明结构收益，不能自动推导回答质量提升。

同一文档在所有组中配对。报告总体分子分母、文档宏平均及各类结果；可按独立文档或近重复来源簇进行配对bootstrap，给策略差值提供95%区间，不把同页段落当成完全独立样本。若区间包含0，只能说证据不足，不能证明策略无效；若独立来源太少，应明确区间与泛化局限。

## 五、失败样例与局限性

本次未执行实验，以下为需纳入验证的假设反例：

1. 整篇文档只放进一个超大块：碎片化趋近于0，但不能据此认定切点选择优秀。
2. 新策略把长段全部丢弃：剩余段落完整，但覆盖率下降；固定全集的缺失指标应暴露该问题。
3. 两组都配置1024 tokens，新策略实际P50显著更大：同上限实验仍混入实际块长效应。
4. overlap显著增加，更多段落被某一重复块完整覆盖：可能是冗余换完整性，应报告重复成本并隔离overlap因素。
5. “增长20%，但仅限海外业务”落入不同块：即使句内切断减少，若必要限定条件未进入模型上下文，不能宣称下游信息完整性改善。

块长既可能是外部参数变化，也可能是策略自身导致的中间结果。实际长度匹配用于检验“收益是否仅靠变长”这一具体问题，不应据此否定策略在生产配置下的总体收益。标注段落也不完全等同语义单元，应补充必要证据完整性。

## 六、结论与下一步

23%降至7%在算术上是下降16个百分点；仅凭这两个数不能确认因果归属。本次也未核实这两个比例本身。

优先取得原始运行、有效配置、逐段标签与全部chunk；其次完成2×2控制和实际长度匹配诊断；最后在固定检索预算下验证证据完整性。确认同等长度、相同覆盖及重叠开销下新策略仍稳定更低，才支持“切分边界质量改善”的归因。最终表述应分别报告长度效应、同长度策略效应和生产配置总体效应。

后续正式运行建议保存在 `backend/eval/data/段落切分长度对照评估-日期-运行编号/`，包括 `运行配置.json`、`逐段结果.jsonl`、`分块结果.jsonl`、`汇总指标.json`、输入和代码指纹；此目录为方案，本次未创建。
