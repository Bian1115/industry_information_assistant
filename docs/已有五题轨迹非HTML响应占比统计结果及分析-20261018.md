# 已有五题轨迹非HTML响应占比统计结果及分析

评估日期：2026-10-18，Asia/Singapore。评估对象：此前冻结的通用研究五题35、31、46、16、49中的URL读取返回。本次为离线类型统计及既有归档复核，没有新增抓取或模型调用。

**历史轨迹中明确检出非HTML响应3个：PDF 2个、Word 1个。按原始请求URL去重为3/289＝1.04%；按读取返回次数为3/302＝0.99%。** 历史去重数据另有173个URL未记录MIME，因此这两个数字是明确检出比例，不能当作类型完全可知时的精确总体占比。

## 数据与配置口径

- 使用2026-10-08冻结、此前网页读取评估反复使用的五个完成运行，原始运行来自2026-10-03。范围限定为这五题，不包含本地全部旧版试跑、后续消融、故障恢复运行或其他任务。
- 对302条读取返回逐条回到五份`智能体原始历史.json`中的`tool_raw_result.payload.value[]`，核对调用编号、轨迹序号、返回索引、请求URL、正文SHA-256、MIME、抽取器、最终URL及缓存标记。
- MIME使用原始`content_type`，去除`;charset=...`等参数并转小写。`text/html`与`application/xhtml+xml`算HTML；PDF、Word及其他非HTML MIME计入分子。空MIME保留未知，不根据URL后缀、乱码标签或失败状态补判类型。
- 按每题规范化原始请求URL取最后一次返回，得到289个URL；本批跨题没有重复请求URL。不按最终跳转URL合并，也不宣称289个URL对应289篇独立内容。13条重复返回保留在302次调用口径中，均为缓存返回；3个非HTML条目没有重复。
- `success`采用历史原始工具状态，不能等同于HTTP成功或正文可用。历史正文标签仅用于说明失败样例，本次未重新进行正文质量判定。
- 补充读取2026-10-17同批289个URL的既有重抓归档，复核全部采集元数据，并验证3份非HTML原始响应的SHA-256、文件长度和文件头。PDF文件头均为`%PDF-`；Word为OLE复合文档文件头，结合`application/msword`和`.doc`路径确认类型。该归档是不同时间的观察，不替代原历史轨迹。

## 已测量、间接推断与尚未评估

**已测量**：五份原始轨迹中302条返回的MIME及相关字段与派生明细全部匹配；289个去重URL中明确PDF 2个、Word 1个；289份已有重抓采集元数据完成核对，3份非HTML原始响应的哈希、长度与文件头验证通过。上述比例均按列明的分母计算。

**间接推断**：3个非HTML样例及既有重抓分布表明，这批URL以HTML为主，非HTML文件是少量但真实存在的输入。历史Word正文失败及PDF乱码结论沿用既有质量标签，不是本次重新测得的质量分数。

**尚未评估**：全部本地历史运行的类型普查；173个缺失MIME条目的原始响应真实类型；重抓失败的55个URL本应返回何种类型；未被读取的附件、HTML内链接附件和后续下载；今天重新访问时的响应；新增Word解析或PDF/OCR方案的效果。

## 结论与下一步建议

对“已有轨迹中明确返回非HTML的比例”，可使用**五题去重URL口径1.04%（2个PDF、1个Word）**；若按工具返回次数则为0.99%。须同时说明历史MIME有缺失，不能用1.04%声称总体类型已完整测清。已有重抓中实际取得的234份可分类输入，非HTML为1.28%，可作为另一时间截面的补充。

下一步优先补齐所有读取路径的MIME及类型判定留存，并对Office等二进制响应显式分流。至少应避免把Word输入HTML提取器后因输出长度充足而标记读取成功。是否增加Word解析器及如何处理扫描PDF，需另做真实文件验证；本次没有实施这些业务改动。
