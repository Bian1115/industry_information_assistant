# 会话成果继承与逐智能体压缩配置实现及回归

评估日期：2026-10-02 至 2026-10-03（本地时间）。对象：同一会话跨研究运行的上下文与成果继承，以及五个研究 Agent 的独立历史压缩配置。本次是离线机制验证，使用本地 Qwen tokenizer、内存历史与模拟模型响应。

## 会话与运行的继承边界

`session_id` 表示用户所在的会话，`run_id` 表示其中一次研究执行。追问创建新 run；技术中断后的恢复继续同一个 run 的冻结配置和执行位置。

新 run 从同一用户、同一 session 下最近一份已完成且有报告的研究继承背景与适用成果。定位由数据库授权查询完成，不接受模型指定父 run。父研究必须属于当前 session、状态为 completed，且图没有待执行节点。程序记录 parent_run_id、检查点编号和报告哈希。来源通过正文哈希与程序编号检查，按本轮允许范围过滤。不同会话不能继承；同 session 的子 run 也不能回读父 run 的 Agent 原始历史。

原有的近期用户/助手消息、指代消解和记忆背景继续通过 research_context 传入。此次补充完整父研究成果桥接：父报告与原文保存在业务状态，给 Architect 的背景索引默认限制为 3000 tokens，包含上一轮问题、大纲和标为节选的章节片段。报告背景不能充当新的事实来源。

关闭追问路由模型时，现在仍可继承：先把父契约标记为待更新，由 Architect 根据本轮原话生成契约补丁，再决定是否复用证据。复用时复制适用的事实、原文、非派生数据与实体，清除旧事实的章节绑定，按新大纲重新研究与写作；换主题时不复用旧事实与旧约束，并清除父成果背景索引。开启路由时保留已有 Writer 修订、Scout 补搜、Architect 重规划路径；路由失败转入 Architect 时保留可用父成果。

父运行的执行位置、迭代次数、节点尝试、工具预算、运行日志和摘要游标不复制，父成果不修改。本轮未显式指定来源范围时，可继承父范围，并重新检查当前后端允许范围；本轮显式范围优先。

## 逐 Agent 方法选择

共用现有 tokenizer、预算、摘要策略、阈值、存储和审计框架，ChiefArchitect、DeepScout、DataAnalyst、LeadWriter、CriticMaster 分别选择方法。每个 Agent 只处理本 run 内属于自己的历史。

| 字段 | 行为 |
| --- | --- |
| enabled | 启用该 Agent 的受管理历史模型视图；关闭后当前输入与业务层会话上下文仍正常提供 |
| reference_materials | 把已结束旧输入中的证据、原稿等长材料替换为可回读的来源编号 |
| artifact_offload | 外置历史工具长正文和已完成输出中的长稿、事实列表或大纲 |
| semantic_summary | 超过阈值时生成并采用该 Agent 自己的历史摘要；关闭时也不读取旧摘要 |
| semantic_verification | 该 Agent 摘要的语义核验，须开启摘要并具备相关框架配置 |

保留历史但关闭压缩：enabled=true，reference_materials、artifact_offload、semantic_summary 均为 false；完整历史仍受最终输入预算检查。enabled=false 关闭该 Agent 的自动内部历史注入，不会关闭当前任务、父成果背景或本轮研究约束。

Writer 旧 source_evidence、claim_evidence、原报告、原章节与章节汇总可引用化；长输出稿件可外置。审核意见、修订决定和未解决项保留，本轮材料保持完整。标记提供 source_id 与原文字符范围，经过同 run/Agent/subtask 的实际读取权限及哈希检查；原记录不截断。摘要只覆盖已结束调用，不覆盖当前输入或在途调用。

Scout 正文提取批次始终独立，即使开启 DeepScout 历史框架，也不在提取批次回放历史、做历史摘要或追加历史回读。其他 Scout 推理调用按其自己的配置选择历史方式。

## 配置与冻结

新增部署配置：

```dotenv
SESSION_RESEARCH_INHERITANCE_ENABLED=1
SESSION_RESEARCH_CONTEXT_TOKENS=3000
AGENT_COMPRESSION_CONFIG=
```

会话成果继承默认开启，与 FOLLOWUP_ROUTER_ENABLED 独立。AGENT_COMPRESSION_CONFIG 留空兼容原有历史配置；此次未修改实际 .env 或重启服务。按需示例：环境变量填入一行 JSON，或通过研究请求的 agent_compression 字段发送相同对象。

```json
{
  "LeadWriter": {
    "enabled": true,
    "reference_materials": true,
    "artifact_offload": true,
    "semantic_summary": true,
    "semantic_verification": false
  },
  "ChiefArchitect": {"enabled": false},
  "DeepScout": {"enabled": false}
}
```

Architect 需要历史摘要时，单独设置 ChiefArchitect.enabled=true、semantic_summary=true，Writer 不受影响。严格拒绝未知 Agent、未知字段和字符串布尔值。引用化或外置须有有界历史回读；摘要核验须具备对应模型和审计配置。

显式上下文消融文件优先，保留完整配置而不被环境覆盖。没有消融文件时，部署基线应用 AGENT_COMPRESSION_CONFIG；新研究请求再按显式传入字段覆盖。最终完整配置在新 run 创建时冻结。续跑不读取新环境覆盖，传入与原冻结状态不同的开关拒绝。旧快照不新增缺省字段，保持原哈希和行为。前端 API 参数类型已增加 agent_compression；没有新增可视化配置控件。

## 局限、结论与下一步

已测量的是机制正确性与输入组织，并非真实模型报告质量或费用。尚未评估真实数据库授权查询、跨进程持久化、契约补丁成功率、指代理解、事实时效性、长期多轮报告质量和累计 token。继承选择最近一份已完成研究，不自动选择任意早期报告。规划看到有界节选，不能保证所有旧章节细节出现在当前输入；完整材料保存在程序快照，不对 Architect 宣称具备尚未实现的任意父报告读取工具。

框架已支持独立开关与成果继承。关闭路由时重新规划并按新大纲写作，不能推断追问费用一定更低；开启路由可利用已有直接修订路径。Scout 当前正文、Writer 本轮证据、过长单句或契约仍受硬预算检查；历史摘要不自动缩短这些当前输入。

没有重启服务、调用线上模型、重跑付费评测或修改历史归档。下一步部署新代码后按需选择 Agent 配置，用同 session 的“取消字数限制”“补充一个维度”“切换主题”三类追问观察父 run、继承材料、新契约与实际 token。在线质量对比须另开新目录，避免和旧代码运行混用口径。
