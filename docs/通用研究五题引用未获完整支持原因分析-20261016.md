# 通用研究五题引用未获完整支持原因分析

分析日期：2026-10-16，Asia/Singapore。

评估对象：通用研究第16、31、35、46、49题于2026-10-03完成的五篇历史报告。本轮补充分析2026-10-07的逐条独立复核结果，沿用原论断、原引用绑定、原证据窗口和原支持标签；未重新生成报告、未调用模型、未补做网络事实核查，不覆盖历史评估。历史标签来自Codex助手复核，非人工金标。

## 一、直接回答

引用支持率为48.65%（144/296）。剩下152组引用关系中，76组只有部分支持、64组无法判断、7组来源不支持、5组来源直接矛盾。

主要问题集中于两处：写出的完整句子超出了所选证据能支持的范围，以及引用对应的正文没有被完整获取或绑定。前两类合计140/152＝92.11%。这个比例描述既有标签构成，不是对具体代码模块的因果归因；尤其无法判断项不能升级成“事实错误”。

## 二、数据与配置口径

- 全文共511条事实论断，其中293条带引用；多来源逐个计数后得到296组“论断—来源”关系。
- 主指标要求单个来源的已保存证据完整支持该论断。`partial`、`unknown`、`unsupported`和`contradicted`都不计入完整支持分子，`unknown`保留在分母。
- 本轮主单位是引用关系，不能与论断数混用。带引用论断中完整支持143条、部分支持76条、未知63条、不支持6条、矛盾5条；关系计数分别为144、76、64、7、5。同一句多引一个来源可能增加一组未知或不支持关系。
- 原五份报告生成时在线引用核验关闭。2026-10-06保存的生产模块结果是后续离线回放，本轮没有重新执行该模块。48.65%描述这批历史报告及既有支持标签，不能代表2026-10-16当前代码重新生成报告的效果。
- 排除未知后的引用支持率为144/232＝62.07%，仅作敏感性分析。把未知移出分母不代表证据问题已经解决。
- 另有218条正文论断未绑定行内引用，它们影响全文有效证据覆盖率，不属于这152组未完整支持的引用关系。

### 1. 部分支持：完整表述比证据更强或更宽

这76组不能统一理解为“整句话编造”。常见情况是数字或主题确实出现过，但写作没有保留关键限定，或者一句复合论断中只有部分属性得到证据支持。以下细分用于解释机制，可能交叉；本轮没有给76组重新进行互斥细分类，不能将历史38条模块误放行样本的分类频次当作全部76组的构成。

| 常见问题 | 可追溯样例 | 原文与报告的差异 |
| --- | --- | --- |
| 计划、可能性或旧时点被强化为现状 | 31-body-131；35-body-049；46-body-076 | 中国科技馆原文说“还会依托大数据”，报告写成已经通过大数据生成成长图谱；其他样例把可实现的优势写成已有效减轻债务，或用旧预测说明报告时点即将纳入碳市场。 |
| 统计分母、年龄条件、统计量发生变化 | 49-body-012、020、031；16-body-014、050 | 医美女性消费者内部的年龄分布被写成全部核心用户构成；限定样本中的美观动机被推广到成人总体；原文“至少提升47.86%”被写成“平均提升47.86%”。 |
| 个别案例扩大为行业，普通结论强化为绝对或显著结论 | 31-body-086；16-body-009、012；35-body-038、075 | 某馆亚洲部的藏品档案被推广到所有美国博物馆每件藏品；存在局限变成“仅适用”；另外加入“首次”“频发”“显著”等缺证限定。 |
| 技术细节、项目归属和功能列表没有被完整支持 | 16-body-022、045、079；35-body-065；49-body-047 | 雷达输入增加未见于所选摘要的模态；两路信号均做帧差的预处理被改成一路原始、一路帧差；其他厂商的功能被归到特定平台，或把分别列出的服务写成统一诊疗路径。 |
| 相关资料被用来证明新增机理或因果链 | 16-body-075、076；35-body-014、052；46-body-043、077 | 任务指标不能独自证明带宽机理；案例和预算数字不能直接证明特定低效主因、显著降本或完整融资因果链。 |

部分支持还包括证据窗口选择过窄：31-body-122在更广来源中可能有补充语句，但当前绑定窗口没有覆盖完整命题；16-body-025、026的型号与规格行没有完整绑定。因此这类问题同时可能来自写作扩展和取证范围，不能将76组全部算作Writer单一环节造成的错误。

### 2. 无法判断：取到的内容不够用，或行内URL未绑定

按本轮64组引用关系统计：

| 原因 | 关系数 | 具体情况与样例 |
| --- | ---: | --- |
| 导航、广告、目录或残缺窗口 | 29 | X-MOL仅搜索导航，凤凰仅广告热榜，道客巴巴仅标题和下载导航，PPT缺表头/数据，行业页仅推荐列表。样例：16-body-011、024、034；31-body-092至103中的相关项；49-body-053、087至090。 |
| 中文编码或PDF字体损坏 | 15 | 数字还在，主体、表头、统计分母和条件无法完整读出。样例：31-body-033、034；35-body-019至021；46-body-013、014、023、059、060；49-body-071至075。 |
| 行内URL未绑定到保存来源 | 11 | 全部来自第31题；原文URL存在，但冻结来源中找不到相应文档，不能把“有链接”视作“已有证据”。样例：31-body-106至113、117至119。 |
| 二进制DOC误当文本 | 5 | 温州DOC保存为OLE二进制乱码，无法核实经费整合、实施状态和降本结论。样例：35-body-002、006、083至085。 |
| 验证码或JavaScript页面 | 3 | ScienceDirect保存了机器人验证和大量脚本，万方保存了安全验证。样例：16-body-053、061；49-body-035。 |
| 摘要不足以判断全文缺项 | 1 | 16-body-089用摘要中没有MAE/RMSE，推断整篇研究未报告误差；这种否定命题需要全文。 |
| 合计 | 64 | 不能据此判断原网页全文一定不支持，也不能判断这些论断一定为假。 |

历史未知原因表按63条联合unknown论断计数；本轮按引用关系计数，多出的1组是16-body-034的X-MOL单来源。该句联合仍为partial，因为另一来源提供了有限支持。该细化已在2026-10-07原始评估中记录，本轮没有改标签。

这些问题会被同源引用重复放大：一份损坏DOC影响5组引用，一条无法绑定的第31题URL影响11条论断。因此关系数量不等于独立故障网页数。

### 3. 来源不支持与直接矛盾：12组

7组不支持对应6条论断：16-body-052、081；35-body-054；46-body-045、050；49-body-022。46-body-045引用两个来源，两组均不支持，所以关系数比论断数多1。

- 引错来源：49-body-022写29.37%的年轻人受社交媒体影响，所引URL实际是数字化正畸宣传文，保存证据没有这个调查比例。其他地方存在相关研究不能补算成这条引用的支持。
- 用相关话题代替目标论据：46-body-045引用两篇房地产资料说明REITs、专项债带来现金流与估值基础，但所选证据没有相应金融工具论据。
- 增加无证机理或因果：16-body-052将测量增益推为突破光学衍射和噪声限制；35-body-054由一个生产设备指标稿推断市政排水缺统一国标且制约PPP复制，超出了引用能支持的命题。

5组直接矛盾对应5条论断：

| ID | 失败样例 |
| --- | --- |

| 49-body-009 | 将19–23、24–28、29–33岁分档相加，写成20–33岁占73%；去掉19岁后不能保留原求和比例。 |

这里的矛盾指与所引来源冲突；本轮没有新增现实真值核查，不将全部不支持关系计为已经证实的现实假事实。

## 五、核验环节为什么没有挡住

历史原始轨迹的在线核验开关关闭，所以这些报告在生成时没有经过该语义核验闭环。不能用后续离线结果描述当时已经执行过的审核效果。

后续离线回放在230条有引用且可判断的论断中，相对既有严格参考标签，仍放行了38/87＝43.68%的未完整支持论断，其中37条partial、1条矛盾；另有11条unknown也被放行，后者未并入前述87条分母。历史分歧分类显示，状态、统计条件、范围与技术细节是这些放行分歧的主要类型。

这些是论断单位的历史模块比较，不应与152组关系单位直接相减。离线模块的错误放行也不能证明每条问题都由某个提示词或聚合规则造成；尚无对应因果消融。

## 七、局限性、结论和下一步

**已测量：** 既有标签下的152组构成、逐题指标、64组未知原因及机器记录一致性。历史支持性判定未重做。

**间接推断：** 写作扩大范围与取证不完整是优先改进方向；部分支持也可能来自证据窗口过窄。当前证据不能确定Writer、Scout、解析器和引用绑定各自贡献了多少因果损失。

**尚未评估：** 76组partial各细分问题的互斥频次、全部论断现实真值、未知来源补取后的支持结果、2026-10-16当前版本支持率及任何修复收益。五题固定且题内事实重复、同源相关；没有人工双标仲裁，不作总体外推。

结论：48.65%的主要损失由76组部分支持和64组未知构成；不能据剩余51.35%推断相同比例的内容为假。关系层面的明确来源不支持与矛盾合计12组，占剩余项7.89%。

下一步建议：先修复正文获取与保存，按MIME正确解析DOC/PDF，检查中文解码与表头，识别导航/验证码并补取正文，同时补齐第31题的URL与来源绑定。随后对部分支持项逐一保留对象、年份、统计分母、年龄、计划状态和原文强度；缺证细节补证或改写，分析性推断标明依据。最后用相同冻结报告与完整证据做核验回放，并单独评估开启在线核验后新生成报告的结果，分别记录证据可用率、严格支持率和修改成功率，才能验证改造实际收益。
