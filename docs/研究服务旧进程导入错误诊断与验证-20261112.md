# 研究服务旧进程导入错误诊断与验证

诊断日期：2026-11-12，Asia/Singapore。

对象：前端研究结果页显示的`cannot import name prepare_parent_replan from service.deep_research_v2.followup_context`。本次为源码、进程及导入机制诊断，未执行报告质量评测。

## 结论

这是后端Python导入错误。研究服务在准备本次研究输入时，请求从`followup_context`模块加载名为`prepare_parent_replan`的函数，但该模块没有提供此函数，因此程序在检索前中断。

证据指向正在运行的旧后端进程与更新后的磁盘源码不一致。Python进程启动后会在内存中保留已加载的模块与函数；修改磁盘文件不会自动替换进程内存中的函数。若旧函数随后才加载另一个已经更新的模块，就可能请求新模块中已经删除的旧函数名。

## 证据边界与下一步

已测量：当前源码内容、文件修改日期、运行进程启动日期、报错日志和新进程导入结果。

间接推断：错误由后端旧进程混用新旧模块导致；本次未直接读取运行中进程的Python对象内存。

尚未评估：后端重启后的真实请求、模型调用、工具执行和最终报告交付。

处理方式是先确认没有其他仍在执行的研究任务，再重启后端，使新进程统一加载当前磁盘源码，然后重新发起研究。刷新前端页面只会重新请求数据，不会让后端重载Python模块。
