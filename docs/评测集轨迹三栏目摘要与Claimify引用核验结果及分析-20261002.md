## 失败样例及根因

1. **NLI 伪矛盾及聚合放大。** 共 9 条原子论断同时存在超过阈值的支持和矛盾窗口。例如“PAC-Net 是被动 NLOS 人体跟踪方法”，一个窗口支持 0.9918，另一个同样描述该方法但混有语义特征检测条目，矛盾分数 0.8916；“NEXTY 未披露算法细节”，完整描述窗口支持 0.9983，简短产品链接条目却给出矛盾 0.9990，后者未明确说披露了细节。当前任一高分矛盾否决，导致误判扩大。分数与原文均在 `同时高分支持与矛盾样例.json`，这些样例支持“部分矛盾是误判”的分析，不能据此宣称所有矛盾均错误。

2. **Claimify 排除真实记忆事实。** 第 16 题“西安交大开展事件相机循环泵故障诊断研究，但未提供定量性能”被解释为“信息缺失不包含可验证命题”；“某 URL 返回 HTTP 404”被解释为与研究问题不相关。两者是可由上下文核验的发生记录/证据缺口，却没有进入 NLI。这说明用研究问答的相关性标准筛摘要记忆，会漏掉操作与状态事实。

3. **排除计划后仍有覆盖缺口。** Claimify 共排除 91 个分句，包含纯标题、任务要求、待完成事项、资源列表，以及上述被误排的事实。要求/待办不适宜直接用普通外部事实 NLI 判断，但应核验“谁在何轮提出、当前是否仍有效、是否已完成”；排除不代表这部分摘要正确。本次未把全部被排除项自动当作通过。

4. **复合条件与数值表达仍可造成信息不足。** IPS 温度补偿结果在输入中有明确温度、距离、误差描述，但不同窗口的 entailment 仅约 0.59–0.64，未达到 0.85。需要区分真正证据缺失、证据窗口组合不当和 NLI 无法识别等价表述。

5. **证据句选择仍会输出越界编号。** 第 31 题 4 个错误均由模型选择当前批次未提供的消息或证据句编号触发，3 个发生在初次证据选择，1 个发生在补检索后的选择。严格校验阻止使用不存在的引用，但本次未进行局部修复重试，相关原子论断记为 error 而不是事实矛盾。摘要分句编号消除了摘要原句匹配问题，不能同时消除这一层的模型编号错误。

## 下一步建议

先修语义核验与覆盖口径：将外部事实、用户要求、待完成状态、已发生操作分别表达和核验；Claimify 对已发生操作和“当前证据未含某字段”的限定描述保留抽取，对纯要求/计划执行会话归属与状态核验。对被排除分句增加审计，不能静默当作全部正确。

证据选择优先最短且完整的主题句/结构行，保留时间、归属和条件；将“未提及”与“明确相反”分开。支持与矛盾同时高分时输出冲突待复核，并用人工标注样本校准 NLI/复核器；不建议只把规则改成支持优先，也不建议仅提高矛盾阈值来掩盖误判。数值、单位、样本和适用条件可增加程序检查。

摘要质量采用生成前的重要信息清单与生成后的逐项覆盖检查，优先保存任务所需的发现、数字及条件、证据缺口、资源和已发生操作；任务约束之外也要有可追溯的关键发现/进度/证据缺口记录。下一轮用相同输入和人工金标做受控对照，再单独验证核验失败阻止提交、删改重写及失败上限的真实闭环。
