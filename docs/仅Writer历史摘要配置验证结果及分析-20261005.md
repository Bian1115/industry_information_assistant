## 数据与配置口径

读取 `backend/.env` 和 `backend/.env.example` 中与智能体上下文相关的字段，独立构造冻结配置；另在清除相关环境覆盖后核对源码部署默认。不将 API 密钥等配置写入验证输出。

新配置为：

```dotenv
AGENT_HISTORY_REPLAY=LeadWriter
AGENT_HISTORY_SUMMARY_ENABLED=1
AGENT_COMPRESSION_CONFIG={"DeepScout":{"enabled":true,"semantic_summary":false,"semantic_verification":false},"LeadWriter":{"enabled":true,"semantic_summary":true,"semantic_verification":false}}
AGENT_SUMMARY_CLAIMIFY_ENABLED=0
```

`enabled=true` 保留 Scout 的历史回放；`semantic_summary=false` 同时停用摘要生成与已保存摘要读取。运行时加载全部未压缩原始历史，忽略旧摘要的覆盖游标，避免停用后旧历史仍被隐藏。原始记录和原摘要未删除。

`legacy_policy()` 的部署回放默认从 DeepScout 改为 LeadWriter。未显式设置逐智能体覆盖时，源码部署默认仅 Writer 回放并摘要；本地及示例配置另为 Scout 开启资料回放与外置。显式实验配置、请求中的逐智能体覆盖、已有运行冻结快照继续按各自配置执行；本次未重写历史运行。

模型调用均用桩；历史服务使用 `MemoryStore`；模拟发送视图使用 `CharCounter`。这只验证开关、游标和注入行为，不代表生产 Qwen 分词统计或真实模型语义表现。

## 局限性及边界

- **已测量**：上述确定性检查、现有回归套件和 HTTP 健康检查。
- **间接推断**：新后端会通过启动时读取的 `.env` 和 `selected_policy()` 将新研究冻结为更新配置；未为验证额外创建真实研究任务。
- **尚未评估**：Scout 停用摘要后的真实长轨迹预算、Writer 摘要语义质量、文献方案在本项目的收益。
- 独立历史套件中的 14 项 PostgreSQL 集成测试未开启，不计为通过；数据库状态读取与 HTTP 健康检查不代替这些集成验证。
- 已保存研究续跑保留原冻结快照，可能继续执行之前的 Scout 摘要策略。此次请求作用于新研究默认，不篡改历史快照。
- 显式配置文件和 API 覆盖仍具有原有优先级；关闭默认摘要并非禁止用户以后显式开启。
- Scout 原始历史仍会增长，现有引用化和外置继续参与控制输入；超过预算时仍遵循既有显式报错路径。
