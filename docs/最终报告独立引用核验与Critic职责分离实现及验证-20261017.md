# 最终报告独立引用核验与Critic职责分离实现及验证

评估及复评日期：2026-10-17，Asia/Singapore。

评估对象：通用 DeepResearch V2 的最终报告引用核验、Critic 职责边界、引用失败处理及相关恢复/会话流程。此次为代码实现与离线机制回归，不是实际模型准确率评估，也没有部署或重启服务、迁移业务数据库。

## 实现范围与数据口径

引用核验模块现在以最终 `final_report` 为独立输入，模型不接收 Writer 的 `claims` 清单或来源支持声明。程序把报告标题、段落、列表、表格行分成有精确偏移的单元，向表格行提供表头上下文；参考文献区用于解析引用，不作为事实正文反复核验。每个单元必须明确返回原子论断、无外部事实或不确定状态，缺单元、重复编号、非法定位、截断输出或超预算不能当作通过。长报告按完整单元分批，最多每批8个单元且完整消息不超过冻结预算与16,000 token中的较小值；单个单元过长时明确失败，不截断其尾部。

程序从最终报告原句解析 Markdown URL、数字引用和引用式链接，再回读已经保存的被引来源。会话RAG检索限定在这些被引正文内；没有RAG时使用完整段落/表格的有界词法回退。其他未被引用的资料不能替代被引来源通过核验，多个被引来源也分别检查支持性。主要结果包含 `missing_citation`、`invalid_citation`、`prediction_as_fact`、`unsupported_citation`，以及原有矛盾/证据不足状态。预测标记由核验模型对照原文限定词判断，不使用“年份较新即预测”的规则。

`report_verification_claims` 保存独立论断及定位，`report_claim_extraction` 保存单元覆盖与API调用用量。对外审计范围为 `final_report_extracted_claims`；`extracted_claims_checked` 表示已抽取论断完成核验，`all_claims_checked` 仍为 `false`，因为逐单元处理不等于语义抽取召回率100%。Writer 声明继续用于写作及历史兼容，默认审计不覆盖它们。

Critic 的提示词聚焦整体逻辑、用户要求覆盖、整体时效和观点平衡；观点平衡归入逻辑维度，沿用逻辑/要求覆盖/时效4:3:2权重，口径版本更新为 `report_review_3d_v2`。Critic 不再负责遗漏引用、单条来源支持性或来源中的预测是否被改成事实。旧检查点中明确属于引用模块的问题保留在 `citation_issue_handoffs`，交接记录不表示已修复。基础来源范围规则仍由确定性门禁执行。

默认 `report_failure_action=audit` 继续记录核验结果；可选删除/改写策略改用独立抽取的论断及位置，处理后从新报告重新提取并核验。执行错误、覆盖不完整和旧版审计不能触发删稿。Critic审核与引用审计继续分别存储和交付，引用失败不会被Critic分数覆盖。

## 失败样例与修正分析

集成首轮8项断言失败和2项错误均保存在首轮日志；没有删除失败记录。主要分为：

1. 旧Writer/首尾继承测试只设置了Writer声明，却直接调用最终报告入口，新增抽取器没有对应桩，因此得到错误审计。最终报告入口测试改为提供独立抽取响应；专门测试历史声明绑定的用例直接调用兼容解析及通用核验接口，保留原有检验目的。
2. 两项表格测试假定检索返回第一条必为Writer原绑定的表格。独立入口按最终引用检索后顺序可能不同，测试改为定位实际表格证据编号并核对整块原文、表头，不依赖返回顺序。
3. 两项Scout生命周期测试仍假定搜索节点会自动运行已从当前主链路移除的事实提炼/核验阶段，调整为验证不会恢复该阶段；独立Scout核验入口的开关测试继续保留。
4. 两项首尾写作测试对已不在Writer模块中的函数做patch，产生AttributeError，改为在函数实际定义处拦截，继续验证整合阶段不全量注入来源原文。
5. Writer改写集成样例此前只有内部证据编号、正文没有行内引用。新的覆盖检查正确拒绝它；样例补上真实正文引用，并为初稿及改稿提供独立抽取桩，继续验证“改写一次仍失败时保留审计并交付”。

## 已测量、间接推断与尚未评估

**已测量：** 本次离线机制回归的通过/失败/跳过计数；完整报告单元进入抽取输入；Writer漏报不会直接清空核验清单；引用缺失与来源错误的程序状态；预测标记及支持性结果的传播；修改后重新抽取与核验；关闭/异常/不完整时不会误报执行通过。API用量字段的传递使用模拟响应测试，未测量实际费用。

**间接推断：** 独立从最终报告提取能减少对Writer自报清单的依赖；限定被引正文及逐来源检查能防止无关来源替代被引来源通过。这些结论由机制和受控样例支持，不是实际报告质量提升幅度。

**尚未评估：** 真实Qwen抽取的论断召回率、引用关联精度、预测混淆识别准确率、支持性判断准确率、医学/行业事实真实性、实际延迟与费用；隔离PostgreSQL及Milvus跳过项；部署后真实请求。未发起付费模型请求，也未对历史报告重新评分。

## 局限性、结论与下一步

单元覆盖账本可检查输入有没有处理，无法证明模型没有漏掉某个单元中的事实。分句/表格行上的引用关联仍依赖提取器提供正确的最小原文定位；同句复合事实、多来源组合推导、特殊Markdown引用格式和表格跨行限定需进一步用真实样本测量。有界检索可能漏掉来源中的相关证据，此时应保留不支持/不完整审计，不解释为现实事实必然错误。支持性分数及预测标记仍是模型判断，尚未校准。

本次已完成引用核验与Critic的职责调整和相关机制验证，默认审计及可选失败处理策略保持现有交付语义。下一步宜建立人工标注的小型最终报告集，覆盖摘要、表格、结论、无引用事实、多个来源及预测限定，分别测量提取召回、引用关联与支持性/预测判断；再启用隔离数据库、向量库与部署后的真实请求验收。
