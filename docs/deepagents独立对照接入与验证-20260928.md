# deepagents独立对照接入与验证

评估日期：2026-09-28。评估对象：deepagents独立端到端研究组的运行适配、工具范围、成本记录和结果导出。用户确认对比端到端研究效果与成本。

## 接入结果

新增独立入口 `backend/eval/scripts/run_deepagents_bench.py`，通过deepagents 0.7.19的 `create_deep_agent` 构建研究图，使用每题独立的StateBackend。复用项目现有博查搜索、网页/PDF读取及来源域名过滤模块，按文件加载叶子模块，避免触发业务包初始化。没有修改业务图、业务依赖清单、环境文件或数据库。

专用环境为 `backend/.venv-deepagents`，直接依赖与完整锁定文件分别为 `backend/requirements-deepagents对照.txt`、`backend/requirements-deepagents锁定.txt`。业务环境核查仍为langgraph 1.2.11、langchain-core 1.5.5，未安装deepagents/langchain/langchain-openai。完整独立依赖版本保存在预检的运行配置中。

配置和运行命令见[使用说明](../backend/eval/configs/deepagents独立对照/使用说明.md)。默认配置[端到端研究.json](../backend/eval/configs/deepagents独立对照/端到端研究.json)声明qwen3-max、6000输出token、32768窗口、900秒、40模型调用、30搜索请求和30网页读取。所有费用单价默认为null，待按实际计价填写。这些默认值尚未完成与业务组的预算配对。

对照保留deepagents原生规划、虚拟文件和上下文管理机制，未接入本项目业务摘要、NLI、独立记忆或Critic。它是整体系统对照，不能归因为单个压缩组件的消融收益。

## 数据与配置口径

机制测试使用真实已安装deepagents图，模型为可执行LangChain接口的确定性桩，搜索和网页读取为桩。测试无付费模型请求、无真实联网搜索。实际DRB数据只进行题号1、中文、limit=1的CLI预检，未启动研究。

运行配置冻结原始题目、提示词、模型与预算、域名范围、相关源码哈希、完整依赖和读取环境摘要。续跑要求快照一致；成功题跳过，失败题新增attempt。结果含DRB兼容 `id/prompt/article` 和逐题状态、token、耗时、工具次数；失败article保持为空，避免误进入仅按article筛选的评分器。

所有attempt成本累加；用量缺失或未配置单价时为null。模型/搜索费用只是显式价格估算，未建模阶梯价、缓存价或本地/远程读取附加成本。失败和取消也保存结果；硬终止留下的未完成attempt会使汇总用量与成本标为不完整。

## 逐类分析与失败样例

1. 实际框架链路：模拟模型依次调用search_web、read_web、write_file，再输出行内来源链接。实际deepagents图成功执行，四次模型调用均被记录，模拟输入token合计40。虚拟文件保存在图状态，未写到业务文件目录。
2. 来源范围：域外URL不触发读取；模型自带site条件被清除后使用配置域名；搜索结果的域外条目被过滤。读取服务原有逐跳限制沿用，未在本轮执行真实重定向网络测试。
3. 资源限制：达到模型调用上限时，后续模拟模型调用没有执行；搜索/读取次数超限被阻止。调用限额报错日志是预期结果，不是测试失败。
4. 用量与成本：模拟已报告用量按显式价格正确汇总；缺少usage_metadata时标记不完整、费用为null。测试中的分数与费用只验证算术口径，不代表实际收费。
5. 续跑：目录已存在必须显式resume，配置不一致拒绝混写；成功结果不会被后续失败覆盖，统一导出每题一行。
6. 失败与取消：超时保存失败；最终状态保存失败时清空article，防止误评分；取消保存interrupted和已有用量，再向上传播取消。
7. 输入校验：测试覆盖指定题号缺失、非法预算/价格和空最终回复的拒绝。重复题号与空prompt也有代码校验，但本轮未单列断言。首题真实输入只做预检，没有测量其生成效果。

所有11项机制断言通过。失败样例均为人为注入的预算、超时、磁盘异常和取消；没有本次真实模型错误或真实网页故障样本。
