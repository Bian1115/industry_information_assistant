# 阿里搜索 MCP 接入验证结果及分析

评估日期：2026-10-05 至 2026-10-06（Asia/Singapore）。
对象：`deep_research_v2` 的 DeepScout 搜索后端切换与百炼 EnhancedSearch MCP 接入。
这是接口和机制验证，以及单题搜索调用对比，不是搜索质量排名或完整报告评估。

## 配置与数据口径

- 项目：`industry_information_assistant`；沿用用户工作区已有实现，在现有 ToolRuntime 入口增加后端。
- 验证环境：`backend/.venv-eval-py311`，Python 3.11.14，MCP SDK 2.3.0，LangGraph 1.2.11。
- 默认选择 `bocha`；真实 `.env` 未改动，示例文件增加 `RESEARCH_SEARCH_PROVIDER` 和 MCP 配置项。
- MCP 地址：`https://dashscope.aliyuncs.com/api/v1/mcps/EnhancedSearch/mcp`；Bearer 认证使用本地百炼 Key。
- 真实工具发现：`search_pro`；只声明 `query`，没有 `count`；schema 最小长度为 2，最大长度为 500。
- 真实搜索测试题只有一个：`大语言模型 医学研究 综述`，配对测试两组最多保留 5 条。
- 最终实现使用 SDK `mode="legacy"` 直接初始化；初版 `auto` 的现代协议探测收到 500 后正常回退，已改进。
- 全网查询，无网站限制；脚本关闭本地搜索缓存，不控制供应商服务端缓存。
- 两次单题配对分别为初版 auto 和最终 legacy 配置，保留历史记录，不混合成统计比较。
- 总计实际调用阿里搜索工具 3 次（含初次原始返回探测），Bocha 搜索 2 次；没有调用真实 LLM。
- 验证所需 MCP、可选 Langfuse 和原项目分词依赖已安装在上述测试环境。其他后端启动环境需要安装对应依赖。

## 逐类分析与失败样例

**通过的机制测试**涵盖：text JSON 与 structuredContent 解析、空结果与错误区分、去重、
非法 URL 过滤、保留排名和缺失日期、服务端 schema 校验、工具名不匹配、缺失凭据、
工具错误不重试、不回退 Bocha、超时与取消传播、搜索预算、网站范围、缓存包含后端和 K、
新运行/续跑后端冻结、图配置注入及 MCP 原始响应埋点。

**两个仍失败的原有断言**：

1. `test_process_exports_only_retained_facts_and_evidence_with_budget_delta`：期望保留 1 条事实，实际为 0。
2. `test_supplementary_process_exports_new_state_and_existing_budget`：期望补搜新增 1 条事实，实际为 0。

使用本次修改前保存的 Scout 源码重新执行这两个测试，同样出现上述失败。
日志包含“没有可在检查预算内完整展示的正文块”；当前 fixture 与正文/事实保留流程的预期不一致。
这证明失败在接入前已经存在；未在本次搜索适配任务中更改事实门禁来满足旧断言。
这些检查仍记为失败，不能宣称完整回归全绿。

早期验证另有两类已解决问题：测试环境缺少可选 Langfuse 和分词依赖；新测试误以为
ToolRuntime 会把工具内部异常包装成 ToolRuntimeError，而实际项目保持原异常，已修正测试预期。

**单题对比**两组均成功取得候选 URL，无调用错误或成功空结果。
MCP 返回的 `hostname/title/snippet/url` 已转为统一字段；日期缺失保持空字符串。
现有网页/PDF 阅读器仍负责取得正文，MCP 搜索摘要不能直接充当正式证据。

## 结论边界与下一步

已测量：阿里 MCP 能通过项目真实工具入口调用；两种后端可通过配置选择；相关机制测试通过。

间接推断：统一结果契约和既有调用入口使 MCP 候选来源可复用后续阅读、抽取和写作流程。
没有据此断言整篇报告质量、最终事实数量或引用正确性。

尚未评估：搜索相关性、权威来源比例、正文可读率、完整报告质量、长期 P95 和实际费用。
示例查询集尚未批量执行；没有对真实医疗问题给出医疗结论。

下一步用相同的 20–50 个医学研究问题做查询级标注，再用独立运行 ID、相同模型、提示词、
预算、网站范围、阅读缓存策略和审核设置进行完整链路配对评估。
另外单独处理两个既有事实埋点 fixture/门禁预期问题。
比较对象是 Bocha 与阿里搜索服务及适配实现；MCP 协议本身不决定搜索质量。
